# ST059 检查账户是否存在不允许销户的限制

## 步骤描述

1.检查销户标志：遍历[账户限制信息]
1）根据$账户限制类型$查询【限制类型信息】获取$销户标志$
2）若$销户标志$为“N-否”，则返回[允许销户标志]为“不允许销户”并中断遍历，否则继续遍历
结束遍历，返回[允许销户标志]为“允许销户”

## 输入

| 字段名 | 类型 | 标记 | 来源实体 | 说明 |
|--------|------|------|----------|------|
| resSeqNo | java.lang.String | 必填 | 对公存款账户限制表（RB_BUS_RESTRAINTS） | 限制编号 |
| restraintType | com.dcits.deposit.enums.RestraintType | 必填 | 对公存款账户限制表（RB_BUS_RESTRAINTS） | 账户限制类型 |
| restraintsStatus | com.dcits.deposit.enums.RestraintsStatus | 必填 | 对公存款账户限制表（RB_BUS_RESTRAINTS） | 限制状态 |
| restraintLevel | com.dcits.deposit.enums.RestraintLevel | 必填 | 对公存款账户限制表（RB_BUS_RESTRAINTS） | 限制级别 |

## 输出

| 字段名 | 类型 | 标记 | 来源实体 | 说明 |
|--------|------|------|----------|------|
| 允许销户标志 | java.lang.String | 非必填 | | 待定：允许销户标志 |
