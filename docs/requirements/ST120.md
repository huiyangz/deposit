# ST120 检查是否存在转账不收不付限制

## 步骤描述

1.获取账户限制信息：根据{账号}、$限制状态$等于"A-生效"查询【账户限制信息】获取[账户限制信息]，必须包括$账户限制类型$、$限制编号$；若没有查到$限制状态$等于"A-生效"的账户限制信息，则转账不收不付标志返回“否”；若查到多条，则逐条限制分别按子步骤2、子步骤3判断，任意一条限制命中转账不收不付限制时，返回该条[账户限制信息]及转账不收不付标志为“是”，全部限制都未命中时返回转账不收不付标志为“否”。

2.获取账户限制类型信息：根据[账户限制信息]中的$账户限制类型$查询【限制类型表】获取$状态$等于"A-生效"的$借贷方控制标志$、$转账标志$；若查不到该$账户限制类型$对应的配置记录，或该配置记录$状态$不是"A-生效"，则视为该限制类型不构成转账不收不付限制，本条限制信息不参与命中判定；全部限制信息都不构成时，转账不收不付标志返回“否”。

3.检查是否存在转账不收不付限制：若限制类型对应的$借贷方控制标志$等于"A-禁止借贷方"且$转账标志$等于"N-禁止转账，则返回[账户限制信息]及转账不收不付标志为“是”，否则返回转账不收不付标志为“否”。
