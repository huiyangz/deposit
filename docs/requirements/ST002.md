# ST002 检查账户到期日

## 步骤描述

1.获取账户到期日：根据{账号}获取【账户信息】获取$账户到期日期$；一个{账号}唯一确定一条账户记录，若查不到该账户，则返回[错误码]“ER0048”

2.检查账户到期日：若[账户到期日期]为空，则返回检查结果为“通过”；若[账户到期日期]小于{交易日期}，则返回[错误码]“ER0054”，否则返回检查结果为“通过”

## 输入

| 字段名 | 类型 | 标记 | 来源实体 | 说明 |
|--------|------|------|----------|------|
| baseAcctNo | java.lang.String | 必填 | | 账号 |
| tranDate | java.util.Date | 必填 | | 交易日期 |

## 输出

| 字段名 | 类型 | 标记 | 来源实体 | 说明 |
|--------|------|------|----------|------|
| acctDueDate | java.util.Date | 非必填 | | 账户到期日期 |
