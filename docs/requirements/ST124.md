# ST124 检查是否存在现金不收不付限制

## 步骤描述

1.获取账户限制信息：根据{账号}、$限制状态$等于"A-生效"查询【账户限制信息】获取[账户限制信息]，必须包括$账户限制类型$、$限制编号$；未查询到生效的限制信息时，直接返回现金不收不付限制标志为“否”，$限制编号$、$账户限制类型$、$限制状态$输出空值；查询到生效限制信息时逐条按其$账户限制类型$继续判断，任一条满足现金不收不付条件即返回现金不收不付限制标志为“是”并回显该条记录对应的$限制编号$、$账户限制类型$、$限制状态$，全部不满足返回现金不收不付限制标志为“否”、三个字段输出空值。

2.获取账户限制类型信息：根据[账户限制信息]中的$账户限制类型$查询【限制类型表】获取$状态$等于"A-生效"的$借贷方控制标志$、$现金标志$；未查询到状态为“A-生效”的配置时，视为该账户限制类型不构成现金不收不付限制，该条限制不满足现金不收不付条件，$状态$、$借贷方控制标志$、$现金标志$输出空值，并继续判断其余限制信息。

3.检查是否存在现金不收不付限制：若限制类型对应的$借贷方控制标志$等于"A-禁止借贷方"且$现金标志$等于"N-禁止现金"，则返回现金不收不付限制标志为“是”，否则返回现金不收不付限制标志为“否”。
