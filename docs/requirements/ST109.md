# ST109 检查限额场景配置是否有效

## 步骤描述

1.获取限额场景控制区间：根据[限额场景编码]查询【限额控制配置】获取$限额控制开始日期$、$限额控制结束日期$、$限额控制开始时间$、$限额控制结束时间$；查出多条配置时，只要其中一条的控制区间覆盖本次交易，即认为该限额场景配置有效；查询无记录，或全部配置的控制区间都未覆盖本次交易时，即认为该限额场景配置无效，由子步骤2返回[限额场景编码]为空。

2.检查交易时间：若{交易日期}在[限额控制开始日期]至[限额控制结束日期]之间（含起止日期），且{交易时间}在[限额控制开始时间]至[限额控制结束时间]之间（含起止时间），则返回[限额场景编码]，否则返回[限额场景编码]为空。限额控制开始日期、限额控制结束日期未设置的，日期侧不限制；限额控制开始时间、限额控制结束时间未设置的，时间侧不限制；某一侧只设置了其中一端的，按已设置的一端判断；两侧都未设置的，本次交易视为落在该配置的有效期内。

## 输入

| 字段名 | 类型 | 标记 | 来源实体 | 说明 |
|--------|------|------|----------|------|
| tranDate | java.util.Date | 必填 | | 交易日期 |
| tranTimestamp | java.lang.String | 必填 | | 交易时间戳 |
| limitSceneNo | java.lang.String | 必填 | | 限额场景编码 |

## 输出

| 字段名 | 类型 | 标记 | 来源实体 | 说明 |
|--------|------|------|----------|------|
| limitSceneNo | java.lang.String | 非必填 | 限额控制配置（RB_LIMIT_CTRL_CONF） | 限额场景编码 |
| limitCtrlBgnDate | java.util.Date | 非必填 | 限额控制配置（RB_LIMIT_CTRL_CONF） | 限额控制开始日期 |
| limitCtrlEndDate | java.util.Date | 非必填 | 限额控制配置（RB_LIMIT_CTRL_CONF） | 限额控制结束日期 |
| limitCtrlBgnTime | java.util.Date | 非必填 | 限额控制配置（RB_LIMIT_CTRL_CONF） | 限额控制开始时间 |
| limitCtrlEndTime | java.util.Date | 非必填 | 限额控制配置（RB_LIMIT_CTRL_CONF） | 限额控制结束时间 |

## 失败处理

本步骤无业务失败场景，失败仅由技术异常传播表达。
