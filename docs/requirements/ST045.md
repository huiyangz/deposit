# ST045 检查限额场景配置是否有效

## 步骤描述

1.获取限额场景控制区间：根据[限额场景编码]查询【限额控制配置】获取$限额控制开始日期$、$限制控制结束日期$、$限制控制开始时间$、$限额控制结束时间$
2.检查交易时间：若{交易日期}或者{交易时间}在[限额控制开始日期]、[限制控制结束日期]、[限制控制开始时间]、[限额控制结束时间]范围内，则返回[限额场景编码]，否则返回[限额场景编码]为空。

## 输入

| 字段名 | 类型 | 标记 | 来源实体 | 说明 |
|--------|------|------|----------|------|
| tranDate | java.util.Date | 必填 | | 交易日期 |
| tranTimestamp | java.lang.String | 必填 | | 交易时间戳 |
| limitSceneNo | java.lang.String | 必填 | | 限额场景编码 |

## 输出

| 字段名 | 类型 | 标记 | 来源实体 | 说明 |
|--------|------|------|----------|------|
| limitSceneNo | java.lang.String | 非必填 | 限额控制配置（RB_LIMIT_CTRL_CONF） | 限额场景编码 |
| limitCtrlBgnDate | java.util.Date | 非必填 | 限额控制配置（RB_LIMIT_CTRL_CONF） | 限额控制开始日期 |
| limitCtrlEndDate | java.util.Date | 非必填 | 限额控制配置（RB_LIMIT_CTRL_CONF） | 限额控制结束日期 |
| limitCtrlBgnTime | java.util.Date | 非必填 | 限额控制配置（RB_LIMIT_CTRL_CONF） | 限额控制开始时间 |
| limitCtrlEndTime | java.util.Date | 非必填 | 限额控制配置（RB_LIMIT_CTRL_CONF） | 限额控制结束时间 |
