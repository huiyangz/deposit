# ST116 检查是否存在转账止付限制

## 步骤描述

1.获取账户限制信息：根据{账号}、$限制状态$等于"A-生效"查询【账户限制信息】获取[账户限制信息]，必须包括$账户限制类型$、$限制编号$；若未查询到记录，视为不存在转账止付限制，返回转账止付标志为“否”并结束，其余输出字段为空值；若查询到多条，逐条执行子步骤2、子步骤3，任一条限制符合子步骤3 的条件即返回“是”并回显该条的限制编号、账户限制类型与限制状态，全部不符合则返回“否”。

2.获取账户限制类型类型：根据[账户限制信息]中的$账户限制类型$查询【限制类型表】获取$状态$等于"A-生效"的$借贷方控制标志$、$转账标志$；若未查询到$状态$等于"A-生效"的配置，视为该条限制不构成转账止付限制，借贷方控制标志与状态输出为空值，继续判断其余限制。

3.检查是否存在转账止付限制：若是限制类型对应的$借贷方控制标志$等于"D-禁止借方"且$转账标志$等于"N-不允许转账"，则返回转账止付标志为“是”，否则返回转账止付标志为“否”。
