# ST086 设置账户开户日期

## 步骤描述

1.获取系统日期：赋值[系统日期]为当前系统日期
2.设置账户开户日期：赋值并返回[账户开户日期]等于[系统日期]

## 输入

| 字段名 | 类型 | 标记 | 来源实体 | 说明 |
|--------|------|------|----------|------|
| runDate | java.util.Date | 必填 | | 核心运行日期 |

## 输出

| 字段名 | 类型 | 标记 | 来源实体 | 说明 |
|--------|------|------|----------|------|
| acctOpenDate | java.util.Date | 非必填 | | 账户开户日期 |

## 失败处理

本步骤无业务失败场景，失败仅由技术异常传播表达。
