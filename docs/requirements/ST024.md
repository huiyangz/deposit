# ST024 检查法人透支金额

## 步骤描述

1.获取靠档跨月季标识：根据{账号}查询《法透协议信息》获取$靠档跨月季标识$
2.赋值靠档计息跨月跨季标志：若[靠档跨月季标识]为“1-跨月”或“2-跨季”，则赋值[靠档计息跨月跨季标志]为“Y-是”，否则赋值[靠档计息跨月跨季标志]为“否”
3.获取单笔透支检查金额：根据[靠档计息跨月跨季标志]查询【法人透支白名单参数表】获取$单笔透支检查金额$
4.检查单笔透支检查金额：若{交易金额}大于[单笔透支检查金额]，则返回[错误码]“ER0061”，否则继续执行。
5.获取当日累计透支额度：根据{账号}访问业务组件《贷款》的业务功能《计算账号当日放款金额合计》，获取[当日累计透支额度]
6.获取同一支付对象单日累计透支金额：根据[靠档计息跨月跨季标志]查询【法人透支白名单参数表】获取$同一支付对象单日累计透支金额$
7.检查同一支付对象单日累计透支金额：若[当日累计透支额度]+{交易金额}大于[同一支付对象单日累计透支金额]，则返回[错误码]“ER0053”，否则跳转至步骤《检查分行法人透支额度》。

## 输入

| 字段名 | 类型 | 标记 | 来源实体 | 说明 |
|--------|------|------|----------|------|
| baseAcctNo | java.lang.String | 必填 | | 账号 |
| tranAmt | java.math.BigDecimal | 必填 | | 交易金额 |

## 输出

| 字段名 | 类型 | 标记 | 来源实体 | 说明 |
|--------|------|------|----------|------|
| isCrossFlag | java.lang.String | 非必填 | | 靠档计息跨月跨季标志 |
| odPtAmt | java.math.BigDecimal | 非必填 | 法人透支白名单参数表（RB_OD_WHITE_LIMIT_INFO） | 单笔透支检查金额 |
| sameObjectPdOdCumulative | java.math.BigDecimal | 非必填 | 法人透支白名单参数表（RB_OD_WHITE_LIMIT_INFO） | 同一支付对象当日累计透支金额 |

外部调用：

- 业务组件《贷款》业务功能《计算账号当日放款金额合计》
  - 调用描述：5.获取当日累计透支额度：根据{账号}访问业务组件《贷款》的业务功能《计算账号当日放款金额合计》，获取[当日累计透支额度]
