# ST114 检查转账止收限制

## 步骤描述

1.获取账户限制信息：根据{账号}、$限制状态$等于"A-生效"查询【账户限制信息】获取[账户限制信息]，必须包括$账户限制类型$、$限制编号$；未查到"A-生效"的账户限制记录时返回转账止收标志“否”并结束本步骤；查到多条"A-生效"的账户限制记录时，逐条执行下述子步骤2、子步骤3，只要其中任一条的限制类型满足$借贷方控制标志$等于"C-禁止贷方"且$转账标志$等于"N-不允许转账"，即返回转账止收标志“是”，全部不满足时返回“否”。

2.获取账户限制类型信息：根据[账户限制信息]中的$账户限制类型$查询【限制类型表】获取$状态$等于"A-生效"的$借贷方控制标志$、$转账标志$；若该限制类型在【限制类型表】中没有$状态$为"A-生效"的配置，则视同该限制类型不构成转账止收限制，$借贷方控制标志$、$转账标志$按空值处理，转账止收标志返回“否”，不因该配置缺失中止本步骤。

3.检查转账止收限制：若限制类型对应的$借贷方控制标志$等于"C-禁止贷方"且$转账标志$等于"N-不允许转账"，则返回转账止收标志为“是”，否则返回转账止收标志为“否”。
