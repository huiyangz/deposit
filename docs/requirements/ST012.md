# ST012 检查账户余额

## 步骤描述

1.获取账户余额信息：根据{账号}查询【账户余额信息】获取$汇总金额$、$冻结金额$、$系统内理财余额$、$透支金额$
2.计算账户可用余额：[账户可用余额]=[汇总金额]-[冻结金额]+[系统内理财余额]+[透支金额]
3.检查可用余额：若[账户可用余额]小于{交易金额}，则跳转至步骤《检查法透标志》，否则跳转至步骤《检查现金支取账户限制》。

## 输入

| 字段名 | 类型 | 标记 | 来源实体 | 说明 |
|--------|------|------|----------|------|
| baseAcctNo | java.lang.String | 必填 | | 账号 |
| tranAmt | java.math.BigDecimal | 必填 | | 交易金额 |

## 输出

| 字段名 | 类型 | 标记 | 来源实体 | 说明 |
|--------|------|------|----------|------|
| totalAmount | java.math.BigDecimal | 非必填 | 对公存款账户余额表（RB_BUS_ACCT_BALANCE） | 汇总金额 |
| pldAmount | java.math.BigDecimal | 非必填 | 对公存款账户余额表（RB_BUS_ACCT_BALANCE） | 冻结金额 |
| finregAmount | java.math.BigDecimal | 非必填 | 对公存款账户余额表（RB_BUS_ACCT_BALANCE） | 系统内理财余额 |
| odAmount | java.math.BigDecimal | 非必填 | 对公存款账户余额表（RB_BUS_ACCT_BALANCE） | 透支金额 |
| acctAvailBal | java.math.BigDecimal | 非必填 | 对公存款账户余额表（RB_BUS_ACCT_BALANCE） | 账户可用余额 |
