# ST105 处理限额

## 步骤描述

1.获取处理方式：根据[限额场景编码]查询【限额控制配置】获取$处理方式$

2.返回处理结果：a.若[处理方式]等于"拒绝"，则返回检查结果为“拒绝”。
b.若[处理方式]等于"提醒"，则返回检查结果为“提醒”；
c.若[处理方式]等于"授权"，则返回检查结果为“授权”。

> 1.获取处理方式：根据[限额场景编码]查询【限额控制配置】获取$处理方式$

问题：查询【限额控制配置】可能返回多条、也可能查询不到记录，子步骤2 判定用的[处理方式]无法唯一确定。

子步骤1 只按[限额场景编码]查询【限额控制配置】，而该表按“限额机构编码＋限额场景编码”存放，同一限额场景在不同限额机构（以及不同的限额机构范围）可以配置不同的处理方式；正文没有说明返回多条时采用哪一条，也没有说明查询不到记录时如何处理，输入中也没有可用于区分机构的“限额机构编码”。按现有写法，[处理方式]取不到唯一取值，子步骤2 的三个分支无法确定返回的检查结果。

修正要求：请确认取用配置的定位口径（例如按“限额机构编码＋限额场景编码”唯一确定一条，或说明返回多条时按什么规则取舍），并明确查询不到记录时本步骤返回的检查结果。
