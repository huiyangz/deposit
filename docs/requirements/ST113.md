# ST113 检查有权机关冻结限制

## 步骤描述

1.获取账户限制信息：根据{账号}、$限制状态$等于"A-生效"查询【账户限制信息】获取[账户限制信息]，必须包括$账户限制类型$、$限制编号$；未查询到"A-生效"的账户限制记录时，有权机关冻结标志不赋值，不再执行子步骤2，直接返回；查询到多条"A-生效"的账户限制记录时，只要其中任一条记录的限制类型在【限制类型表】中的$有权机关冻结标志$取值为"Y-是"（即码值"Y"，表示该限制属于有权机关冻结），有权机关冻结标志即取该值返回；【限制类型表】的$有权机关冻结标志$取值为"N-否"或空值时，表示该限制不属于有权机关冻结；全部记录均不表示属于有权机关冻结时，有权机关冻结标志不赋值。

2.获取有权机关冻结标志：根据[账户限制信息]中的$账户限制类型$查询【限制类型表】获取$状态$等于"A-生效"的$有权机关冻结标志$赋值并返回[有权机关冻结标志]；该账户限制类型在【限制类型表】中没有$状态$为"A-生效"的记录时，视为该限制类型不构成有权机关冻结限制，本步骤不再按该限制类型返回值，有权机关冻结标志不赋值。

## 输入

| 字段名 | 类型 | 标记 | 来源实体 | 说明 |
|--------|------|------|----------|------|
| baseAcctNo | java.lang.String | 必填 | | 账号 |

## 输出

| 字段名 | 类型 | 标记 | 来源实体 | 说明 |
|--------|------|------|----------|------|
| ahBuFlag | java.lang.String | 非必填 | | 有权机关冻结标志 |

## 失败处理

本步骤无业务失败场景，失败仅由技术异常传播表达。
