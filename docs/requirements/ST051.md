# ST051 检查账户是否存在限制

## 步骤描述

1.获取主账户账号：若上送的{账号}是子账户，则根据{账号}查询【账户信息】获取$主账户账号$，否则继续执行。
2.设置待查账户：若上送的{账号}是子账户，则赋值[待查账户]为[主账户账号]，否则赋值[待查账户]为{账号}。
3.获取账户限制：根据[待查账户]查询【账户限制信息表】获取$限制状态$等于"A-生效"的[账户限制信息]，必须包括$账户限制类型$、$限制编号$
4.检查账户是否存在限制：赋值账户限制信息并返回[账户限制信息]。

## 输入

| 字段名 | 类型 | 标记 | 来源实体 | 说明 |
|--------|------|------|----------|------|
| baseAcctNo | java.lang.String | 必填 | | 账号 |

| 字段名 | 类型 | 标记 | 来源实体 | 说明 |

| leadAcctFlag | java.lang.String | 非必填 | 对公存款账户主表（RB_BUS_ACCT） | 主账户标志 |

| restraintsStatus | com.dcits.deposit.enums.RestraintsStatus | 非必填 | 对公存款账户限制表（RB_BUS_RESTRAINTS） | 限制状态 |
| restraintType | com.dcits.deposit.enums.RestraintType | 非必填 | 对公存款账户限制表（RB_BUS_RESTRAINTS） | 账户限制类型 |
