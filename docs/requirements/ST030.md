# ST030 检查对手账户是否能够入账

## 步骤描述

1.获取对手账户状态：根据{对手账号}查询【账户信息】获取$账户状态$
2.获取对手账户转账止付标志：根据{对手账号}访问业务组件《检查限制组件》的任务《检查账户限制》的步骤《检查是否存在转账止付限制》，获取[现金止收标志]
3.获取对手账户转账不收不付标志：根据{对手账号}访问业务组件《检查限制组件》的任务《检查账户限制》的步骤《检查是否存在转账不收不付限制》，获取[现金止收标志]
4.检查对手账户是否能够交易：根据[对手账户状态]，[对手账户转账止付标志]，[对手账户转账不收不付标志]执行规则《检查账户是否能够入账》,获取[入账标志]
5.检查入账标志：若[入账标志]为“允许”，则返回检查结果为“通过”，否则返回[错误码]“ER0077”
