# ST125 检查是否存在属性限制

## 步骤描述

1.获取属性级限制：根据{账号}查询【账户限制信息表】获取$限制状态$等于"A-生效"且$限制级别$等于"NATURE-账户属性限制"的[账户限制信息]，必须包括$账户限制类型$、$限制编号$；未查到记录时限制编号、账户限制类型、限制状态、限制级别均为空值；查得多条记录时按$限制编号$升序取第一条，回显该条的限制编号、账户限制类型、限制状态、限制级别

2.检查是否存在属性限制：若{账户限制信息}等于空，则返回[属性限制标志]为“否”，否则返回[属性限制标志]为“是”。
