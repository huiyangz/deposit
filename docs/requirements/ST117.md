# ST117 检查质押类限制

## 步骤描述

1.获取账户限制信息：根据{账号}、$限制状态$等于"A-生效"查询【账户限制信息】获取[账户限制信息]，必须包括$账户限制类型$、$限制编号$；未查询到记录时，[质押标志]不赋值，不再执行子步骤2，直接返回
2.获取质押标志：根据[账户限制信息]中的$账户限制类型$查询【限制类型表】获取$状态$等于"A-生效"的$质押标志$赋值并返回[质押标志]；[账户限制信息]有多条记录时，只要其中任一条记录的限制类型在【限制类型表】中的$质押标志$表示存在质押，[质押标志]即取该值返回；全部记录均不表示存在质押，或限制类型在【限制类型表】中无"A-生效"记录时，[质押标志]不赋值
