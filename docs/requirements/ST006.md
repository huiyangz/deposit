# ST006 检查法透标志

## 步骤描述

1.获取交易借贷标志：根据{交易类型}查询【交易类型定义】获取对应的$借贷标志$
2.检查是否可透支：若[借贷标志]等于“D-借方”且{法人透支检查标志}等于“Y-是”，则跳转至步骤《检查靠档标识》，否则返回[错误码]“ER0060”

## 输入

| 字段名 | 类型 | 标记 | 来源实体 | 说明 |
|--------|------|------|----------|------|
| 法人透支检查标志 | java.lang.String | 必填 | | 法人透支检查标志 |
| tranType | com.dcits.deposit.enums.TranType | 必填 | | 交易类型 |

## 输出

| 字段名 | 类型 | 标记 | 来源实体 | 说明 |
|--------|------|------|----------|------|
| crDrInd | com.dcits.deposit.enums.CrDrInd | 非必填 | 交易类型定义表（RB_TRAN_DEF） | 借贷标志 |

## 相关枚举

| 枚举 | 别名 |
|------|------|
| 交易类型 | 交易类型、输入数据-交易类型 |
| 借贷标志 | 借贷标志、输出数据-借贷标志 |

## 补充说明

- {交易类型,输入数据-交易类型}取值来源于代码[交易类型]，对应枚举类-类名：com.dcits.deposit.enums.TranType
- {借贷标志,输出数据-借贷标志}取值来源于代码[借贷标志]，对应枚举类-类名：com.dcits.deposit.enums.CrDrInd
