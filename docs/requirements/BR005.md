# BR005 检查允许转久悬标志

- 规则类型：断言类

## 规则描述

a.若 {允许账户转久悬标志} 等于"Y-是"且{是否允许转久悬}等于“N-否”，则返回否；
b.若 {允许账户转久悬标志} 等于"N-否""且{是否允许转久悬}等于空，则返回否；
