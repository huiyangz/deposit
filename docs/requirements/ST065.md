# ST065 检查分位金额

## 步骤描述

1.获取分位处理金额分位上限：根据预设参数“LIMIT_CENT_AMT”获取系统配置的$分位处理金额分位上限$
2.检查分位处理金额分位上限：若{分位金额}小于等于[分位处理金额分位上限]，则返回检查结果为“通过”，否则返回[错误码]“ER0069”

## 输入

| 字段名 | 类型 | 标记 | 来源实体 | 说明 |
|--------|------|------|----------|------|
| 分位金额 | java.math.BigDecimal | 必填 | | 分位金额 |
| 分位处理金额分位上限 | java.lang.String | 必填 | | 分位处理金额分位上限 |

## 输出

| 字段名 | 类型 | 标记 | 来源实体 | 说明 |
|--------|------|------|----------|------|
| paraValue | java.lang.String | 非必填 | | 参数值 |
