# ST007 检查对手账户是否存在

## 步骤描述

1.获取对手账户信息：根据{对手账号}查询【账户信息】获取[对手账户信息]
2.检查对手账户信息存在性：若[对手账户信息]为空，则返回[错误码]“ER0081”，否则返回检查结果为“通过”

## 输入

| 字段名 | 类型 | 标记 | 来源实体 | 说明 |
|--------|------|------|----------|------|
| othBaseAcctNo | java.lang.String | 必填 | | 对手账号 |

| 字段名 | 类型 | 标记 | 来源实体 | 说明 |
|--------|------|------|----------|------|
| internalKey | java.lang.Integer | 非必填 | | 账户内部键值 |
| baseAcctNo | java.lang.String | 非必填 | | 账号 |
| acctStatus | com.dcits.depsit.enums.AcctStatus | 非必填 | | 账户状态 |

## 相关枚举

|------|------|
