# ST017 检查币种一致性

## 步骤描述

1.检查币种一致性：若{交易币种}与{账户币种}不一致，则返回[错误码]“ER0051”，否则返回检查结果为“通过”

## 输入

| 字段名 | 类型 | 标记 | 来源实体 | 说明 |
|--------|------|------|----------|------|
| tranCcy | com.dcits.depsit.enums.Ccy | 必填 | | 交易币种 |
| acctCcy | com.dcits.depsit.enums.AcctCcy | 必填 | | 账户币种 |

## 相关枚举

| 枚举 | 别名 |
|------|------|
| 货币币种 | 交易币种、输入数据-交易币种 |
| 账户币种 | 账户币种、输入数据-账户币种 |

## 补充说明

- {交易币种,输入数据-交易币种}取值来源于代码[货币币种]，对应枚举类-类名：com.dcits.depsit.enums.Ccy
- {账户币种,输入数据-账户币种}取值来源于代码[账户币种]，对应枚举类-类名：com.dcits.depsit.enums.AcctCcy
