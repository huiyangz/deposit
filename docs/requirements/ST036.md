# ST036 检查黑名单

## 步骤描述

1.获取黑名单检查标志与服务状态：根据{接口服务代码}、{接口服务类型}查询【核心服务定义表】获取[服务信息列表]，包括$黑名单检查标志$与$服务状态$
2.检查接口是否允许检查黑名单：若[服务信息列表]中存在$服务状态$等于"A-生效"，且$黑名单检查标志$等于“Y-是”的记录，则跳转至子步骤《获取黑名单信息》，否则返回检查结果为“通过”。
3.获取黑名单信息：根据{客户号}或{身份证信息}或{账号}查询【名单信息表】获取$黑名单状态$为“生效”的$名单类型代码$，将获取的信息赋值给[黑名单信息]。
4.检查是否存在黑名单：若[黑名单信息]不为空，则跳转至子步骤《获取黑名单检查规则编号》，否则返回检查结果为“通过”。
5.获取黑名单检查规则编号：根据$名单类型代码$查询【名单类型表】获取对应的$黑名单检查规则编号$。
6.检查黑名单检查规则编号：若[黑名单检查规则编号]不等于空，则跳转至子步骤《获取黑名单限制操作标识》，否则返回检查结果为“通过”。
7.获取黑名单限制操作标识：根据[黑名单检查规则编号]查询【名单限制规则表】获取[名单限制规则信息]，其中必须包括$黑名单限制操作标识$$介质$$限制机构范围$
8.检查黑名单是否是检查类：若[名单限制规则信息]的$黑名单限制操作标识$等于"E-检查类"，则跳转至子步骤《获取事件类型》，否则返回检查结果为“通过”。
9.获取事件类型：根据{事件类型}、{交易类型}、{渠道类型}、{交易码}、{服务代码}、{接口服务类型}、{接口服务代码}查询【名单检查范围表】获取所有的$事件类型$
10.获取名单不检查范围列表：根据{交易类型}、{渠道类型}、{交易码}、{服务代码}、{接口服务类型}、{接口服务代码}以及上一步提取的[事件类型]查询【名单不检查范围表】获取[名单不检查范围信息]
11.检查名单不检查范围：若[名单不检查范围信息]不为空，则返回检查结果为“通过”；否则继续执行。
12.检查介质：若上送的{凭证种类}在[名单限制规则信息]的$介质$范围内，则继续执行，否则返回检查结果为“通过”。
13.获取账户开立行行号：根据{账号}查询【账户信息】获取$账户开立行行号$
14.检查机构：若[名单限制规则信息]的$限制机构范围$等于“B-下级机构”，且[账户开立行行号]等于当前{交易机构}或者当前{交易机构}的下级机构，则继续执行，否则返回检查结果为“通过”。
15.获取黑名单处理方式：根据[黑名单检查规则编号]查询【黑名单信息】获取$处理方式$
16.检查处理方式：a.若[处理方式]等于"拒绝"，则返回检查结果为“拒绝”；
b.若[处理方式]等于"授权"，则返回检查结果为“授权”；
c.若[处理方式]等于"提醒"，则返回检查结果为“提醒”。
