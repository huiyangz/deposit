# ST061 检查是否存在属性限制

## 步骤描述

1.获取属性级限制：根据{账号}，$限制状态$等于"A-生效"且$限制级别$等于"NATURE-账户属性限制"查询【账户限制信息表】获取[账户限制信息]（集合），必须包括$账户限制类型$、$限制编号$
2.检查是否存在属性限制：若[账户限制信息]（集合）等于空，则返回[属性限制标志]为“否”，否则返回[属性限制标志]为“是”。

## 输入

| 字段名 | 类型 | 标记 | 来源实体 | 说明 |
|--------|------|------|----------|------|
| baseAcctNo | java.lang.String | 必填 | | 账号 |
