# ST101 获取限额场景编码

## 步骤描述

1.获取允许自定义标识：根据[限额场景编码]查询【限额控制配置表】获取$允许自定义标识$；同一[限额场景编码]在【限额控制配置表】中只应有一条配置记录，按该条记录的$允许自定义标识$、$仅检查客户自定义标志$取值；查询到多条配置记录或查询不到配置记录时，返回[限额场景编码]为空。

2.获取限额信息：若[允许自定义标识]为"N-否 ",则返回[限额场景编码]，否则跳转至子步骤《获取自定义限额》
3.获取自定义限额：根据[客户号]和[限额场景编码]查询【限额控制客户自定义配置表】，获取$生效日期$小于等于{交易日期}的自定义限额；查询到多条记录时，取$生效日期$离{交易日期}最近的一条作为[自定义限额]；查询不到记录时，视为[自定义限额]不存在。

4.获取限额值：检查[自定义限额]，获取对应限额信息:
1.若[自定义限额]存在且$临时限额标志$等于"Y-是"：{交易日期}大于$失效日期$时返回[限额场景编码]为空；$失效日期$为空或{交易日期}小于等于$失效日期$时，返回[限额场景编码]。
2.若[自定义限额]存在且$临时限额标志$不等于"Y-是"（包括为空），则返回[限额场景编码]。

3.若[自定义限额]不存在且限额控制配置表中$仅检查客户自定义标志$等于"Y-是"，则返回[限额场景编码]为空。
4.若[自定义限额]不存在且限额控制配置表中$仅检查客户自定义标志$不等于"Y-是"（包括为空），则返回[限额场景编码]。

## 失败处理

本步骤无业务失败场景，失败仅由技术异常传播表达。
