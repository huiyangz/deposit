# ST044 登记累计限额

## 步骤描述

1.登记累计限额：若[限额检查结果]为“未超限”，且[限额累计金额]等于0或者[限额累计笔数]等于0，则登记限额信息，$限额场景编码$等于[限额场景编码]，$限额检查对象值$根据{限额场景码}配置的$限额检查对象类型$赋值为{账号}或者{客户号}，$限额累计金额$等于{交易金额}，$限额累计笔数$等于1，$生效日期$等于{系统日期}，$失效日期$等于{系统日期}加[限额场景编码]配置的$周期类型$$周期值$，其他字段的取值按照系统规则自动生成。

## 输入

| 字段名 | 类型 | 标记 | 来源实体 | 说明 |
|--------|------|------|----------|------|
| 限额检查结果 | java.lang.String | 必填 | | 限额检查结果 |
| baseAcctNo | java.lang.String | 必填 | | 账号 |
| clientNo | java.lang.String | 必填 | | 客户号 |
| tranAmt | java.math.BigDecimal | 必填 | | 交易金额 |
| limitSceneNo | java.lang.String | 必填 | | 限额场景编码 |
| limitSumAmt | java.math.BigDecimal | 必填 | | 限额累计金额 |
| 否 | java.lang.Integer | 必填 | | 限额累计笔数 |
| runDate | java.util.Date | 必填 | 系统日期表（FM_DATE） | 核心运行日期 |

## 输出

| 字段名 | 类型 | 标记 | 来源实体 | 说明 |
|--------|------|------|----------|------|
| limitSceneNo | java.lang.String | 非必填 | 限额累计信息表（RB_LIMIT_SUM_INFO） | 限额场景编码 |
| checkObjVal | java.lang.String | 非必填 | 限额累计信息表（RB_LIMIT_SUM_INFO） | 限额检查对象值 |
| limitSumAmt | java.math.BigDecimal | 非必填 | 限额累计信息表（RB_LIMIT_SUM_INFO） | 限额累计金额 |
| 否 | java.lang.Integer | 非必填 | 限额累计信息表（RB_LIMIT_SUM_INFO） | 限额累计笔数 |
| effectDate | java.util.Date | 非必填 | 限额累计信息表（RB_LIMIT_SUM_INFO） | 生效日期 |
| expireDate | java.util.Date | 非必填 | 限额累计信息表（RB_LIMIT_SUM_INFO） | 失效日期 |
