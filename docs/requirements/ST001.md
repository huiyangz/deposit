# ST001 检查对手账户凭证状态

## 步骤描述

1.获取凭证挂失信息：根据{账号}，$凭证挂失状态$为“A-生效”查询【凭证挂失信息】获取[凭证挂失信息]（集合），必须包括$挂失编号$
2.检查凭证挂失信息：若[凭证挂失信息]（集合）不为空，则返回[错误码]“ER0068”，否则返回检查结果为“通过”

## 输入

| 字段名 | 类型 | 标记 | 来源实体 | 说明 |
|--------|------|------|----------|------|
| baseAcctNo | java.lang.String | 必填 | | 账号 |

|--------|------|------|----------|------|
| voucherLostStatus | com.dcits.deposit.enums.VoucherLostStatus | 非必填 | | 凭证挂失状态 |
| lostType | com.dcits.deposit.enums.LostType | 非必填 | 凭证挂失登记簿（RB_VOUCHER_LOST） | 挂失类型 |
| lostNo | java.lang.String | 非必填 | 凭证挂失登记簿（RB_VOUCHER_LOST） | 挂失编号 |
| voucherNo | java.lang.String | 非必填 | 凭证挂失登记簿（RB_VOUCHER_LOST） | 凭证号 |
