# ST001 检查对手账户凭证状态

## 步骤描述

1.获取凭证挂失状态：根据{账号}查询【凭证挂失信息】；查询结果为多条时，只要存在任一条仍处于挂失生效状态的挂失登记，即取该条记录的$凭证挂失状态$；查询无记录时$凭证挂失状态$为空

2.检查凭证挂失状态：若[凭证挂失状态]是“USE-使用”，则返回[错误码]“ER0068”，否则返回检查结果为“通过”

## 输入

| 字段名 | 类型 | 标记 | 来源实体 | 说明 |
|--------|------|------|----------|------|
| othBaseAcctNo | java.lang.String | 必填 | | 对手账号 |

## 输出

| 字段名 | 类型 | 标记 | 来源实体 | 说明 |
|--------|------|------|----------|------|
| voucherLostStatus | com.dcits.depsit.enums.VoucherLostStatus | 非必填 | | 凭证挂失状态 |
