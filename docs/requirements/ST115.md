# ST115 检查账户是否存在限制

## 步骤描述

1.获取主账户账号：若上送的{账号}在【账户信息】中的「主账户标志」表明其不是主账户，则按该记录的「上级账户内部键」再查询【账户信息】，取查得账户的账号作为$主账户账号$，否则继续执行。按{账号}查询【账户信息】查不到记录或查到多条记录时，返回错误码"ER0048"（账户不存在）并结束本步骤。
2.设置待查账户：若上送的{账号}不是主账户，则赋值[待查账户]为[主账户账号]，否则赋值[待查账户]为{账号}。

3.获取账户限制：根据[待查账户]查询【账户限制信息表】获取$限制状态$等于"A-生效"的[账户限制信息]，必须包括$账户限制类型$、$限制编号$；查不到记录时限制编号、账户限制类型、限制状态均为空值；查得多条记录时按$限制编号$升序取第一条，回显该条的限制编号、账户限制类型、限制状态

4.检查账户是否存在限制：赋值账户限制信息并返回[账户限制信息]。
