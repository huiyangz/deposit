# ST107 匹配限额场景

## 步骤描述

1.获取规则关系表达式：根据业务场景中的因子查询【限额规则关系表】获取配置好的$规则关系表达式$

2.获取限额场景编码列表：根据[关系规则表达式]查询【限额规则关系表】获取其对应的[限额场景编码列表]，包括$限额场景编码$

3.检查是否匹配到限额场景：遍历[限额场景编码列表]：
1.根据$限额场景编码$查询【限额场景定义表】获取$启用标志$等于"Y-启用"的[配置数据]；
2.若[配置数据]不为空，则中断本次遍历，并返回检查结果为“已匹配到限额场景”；
3.若[配置数据]为空，则继续检查下一个限额场景编码；全部检查完仍未匹配到限额场景时，返回检查结果为“未匹配到限额场景”

## 输入

|--------|------|------|----------|------|
| 因子名称 | java.lang.String | 必填 | | 因子名称 |

## 输出

| 字段名 | 类型 | 标记 | 来源实体 | 说明 |

| relationLimitSceneNo | java.lang.String | 非必填 | 限额规则关系（RB_LIMIT_RULE_RELATION） | 关系表中查询到的候选限额场景编码 |
| ruleRelationExpr | java.lang.String | 非必填 | 限额规则关系（RB_LIMIT_RULE_RELATION） | 关系规则表达式 |
| limitSceneNo | java.lang.String | 非必填 | 限额场景定义（RB_LIMIT_SCENE_DEF） | 匹配到的限额场景编码 |

| validFlag | java.lang.String | 非必填 | 限额场景定义（RB_LIMIT_SCENE_DEF） | 启用标志 |
| matchResult | java.lang.String | 必填 | | 检查结果：已匹配到限额场景 / 未匹配到限额场景 |

## 失败处理

本步骤无业务失败场景，失败仅由技术异常传播表达。

## 已接受的需求处理结论

以下事项已按需求处理流程放行，后续生成与审核不得重复以这些事项阻断。处理记录不等同于补充了未写明的业务取值。

> 1.获取规则关系表达式：根据业务场景中的因子查询【限额规则关系表】获取配置好的$规则关系表达式$

问题：子步骤1 的查询条件“因子”在【限额规则关系表】里没有对应字段，取不到要用的$规则关系表达式$。

【限额规则关系表】（RB_LIMIT_RULE_RELATION）只有规则编号、关系规则表达式、限额场景编码、规则描述四个业务字段，另有创建、修改时间戳，没有存放“因子”的列；本组件别处也没有“因子”的定义，输入表只给了“因子名称”。因此确定不了按哪一列查询，也确定不了查到多条记录时以哪一条的表达式为准（输出的关系规则表达式只有一个）。子步骤2、子步骤3 因此都取不到数据，本步骤对任何因子都只能得出“未匹配到限额场景”。

修正要求：请明确“因子名称”对应【限额规则关系表】的哪一列（该表可作查询条件的是规则编号、关系规则表达式、限额场景编码、规则描述），以及按该条件查到多条记录时以哪一条为准。
