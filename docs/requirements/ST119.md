# ST119 检查是否存在止付限制

## 步骤描述

1.获取账户限制信息：根据{账号}、$限制状态$等于"A-生效"查询【账户限制信息】，获取该账号全部“生效”状态的限制记录（可能为0条或多条），必须包括$账户限制类型$、$限制编号$；查询无记录时，返回止付标志为“否”，输出表中的限制编号、限制类型、限制状态、借贷方控制标志、状态均为空值；查询到多条记录时，逐条执行子步骤2、3，任意一条记录的借贷方控制标志为"D-禁止借方"即返回止付标志为“是”，全部记录均不满足时返回止付标志为“否”（子步骤3的“否则”分支只表示该条记录不满足，不结束检查）；输出表中的限制编号、限制类型、限制状态回显命中的记录，命中多条时取限制编号最小的一条，编号大小按限制编号所表示的数字比较，位数不同时以数字大小为序（如“9”小于“10”）。

2.获取借贷方控制标志：根据[账户限制信息]的$账户限制类型$在【限制类型表】获取$状态$等于"A-生效"的$借贷方控制标志$；该限制类型在【限制类型表】中没有“生效”记录时，视为该条限制不构成止付限制，不参与子步骤3的止付判断，其$借贷方控制标志$与$状态$输出为空值。

3.检查是否存在止付限制：若[借贷方向控制标志]等于"D-禁止借方"，则返回止付标志为“是”，否则返回止付标志为“否”。
