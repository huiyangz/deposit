# ST108 登记累计限额

## 步骤描述

1.登记累计限额：若[限额检查结果]为“未超限”，且[限额累计金额]等于0或者[限额累计笔数]等于0，则登记限额信息，$限额场景编码$等于[限额场景编码]，$限额检查对象值$根据{限额场景码}配置的$限额检查对象类型$赋值为{账号}或者{客户号}，$限额累计金额$等于{交易金额}，$限额累计笔数$等于1，$生效日期$等于{系统日期}，$失效日期$等于{系统日期}加[限额场景编码]配置的$周期类型$$周期值$，其他字段的取值按照系统规则自动生成。

问题：缺少“周期类型”“周期值”的配置来源，登记记录的“失效日期”无法唯一确定。

正文要求 $失效日期$ 等于{系统日期}加[限额场景编码]配置的$周期类型$、$周期值$，但没有说明该周期配置存放于哪张表：【限额场景定义表】只有检查对象类型、限额大类、限额折算方式等列，没有周期类型与周期值；本组件内配置了期限类型与周期值的只有【限额控制配置表】，该表按“限额机构编码＋限额场景编码”存放，同一限额场景在不同限额机构可以有多条，取哪一条、查不到配置时如何处理都没有说明。按现有写法，登记记录的失效日期无法确定。

修正要求：请确认周期类型与周期值的配置载体（是否为【限额控制配置表】），以及同一场景存在多条配置时取哪一条、查无配置时失效日期如何处理。
