# DT002 检查账户是否能够入账

- 规则类型：决策类

## 规则描述

a.若[账户状态]为“新建”，则返回[入账标志]为“允许”
b.若[账户状态]为“待激活”且[账户转账止付标志]为“是”且[账户转账不收不付标志]为“否”，则返回[入账标志]为“允许”
c.若[账户状态]为“活动”且[账户转账止付标志]为“否”且[账户转账不收不付标志]为“否”，则返回[入账标志]为“允许”
d.若[账户状态]为“久悬”且[账户转账不收不付标志]为“否”，则返回[入账标志]为“不允许”
e.若[账户状态]为“转营业外”且[账户转账不收不付标志]为“否”，则返回[入账标志]为“不允许”
f.否则，返回[入账标志]为“不允许”

|--------|------|------|----------|------|

| acctTranNoRecvNoPayFlag | java.lang.String | 必填 | | 账户转账不收不付标志，取值：“Y-是”、“N-否” |
