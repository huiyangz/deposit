# ST033 检查账户余额类型一致性

## 步骤描述

1.获取转出账户余额类型：根据{账号}查询【账户信息】获取$余额类型$
2.获取转入账户余额类型：根据{对手账号}查询【账户信息】获取$余额类型$
3.检查账户余额类型一致性：若转出账户的[余额类型]与转入账户的[余额类型]不一致，则返回[错误码]“ER0075”，否则返回检查结果为“通过”。

## 输入

| 字段名 | 类型 | 标记 | 来源实体 | 说明 |
|--------|------|------|----------|------|
| baseAcctNo | java.lang.String | 必填 | | 账号 |
| othBaseAcctNo | java.lang.String | 必填 | | 对手账号 |

## 输出

| 字段名 | 类型 | 标记 | 来源实体 | 说明 |
|--------|------|------|----------|------|
| rbAcctType | com.dcits.deposit.enums.RbAcctType | 非必填 | 对公存款账户主表（RB_BUS_ACCT） | 存款账户类型 |
