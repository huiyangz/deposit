# DT001 检查账户是否能够出账

- 规则类型：决策类

## 规则描述

a1.若[账户状态]为“新建”且[账户转账止付标志]为“否”且[账户转账不收不付标志]为“否”，则返回[出账标志]为“允许”
a2.若[账户状态]为“新建”且[账户转账止付标志]为“是”，则返回[出账标志]为“不允许”
a3.若[账户状态]为“新建”且[账户转账不收不付标志]为“是”，则返回[出账标志]为“不允许”

c.若[账户状态]为“待激活”且[账户转账止付标志]为“是”且[账户转账不收不付标志]为“否”，则返回[出账标志]为“不允许”
d.若[账户状态]为“正常”且[账户转账止付标志]为“否”且[账户转账不收不付标志]为“否”，则返回[出账标志]为“允许”
e.若[账户状态]为“久悬”且[账户转账不收不付标志]为“是”，则返回[出账标志]为“不允许”
f.若[账户状态]为“转营业外”且[账户转账不收不付标志]为“是”，则返回[出账标志]为“不允许”
g.若[账户状态]为“销户”，则返回[出账标志]为“不允许”
h.未命中上述任一分支的账户状态与标志组合，一律返回[出账标志]为“不允许”
