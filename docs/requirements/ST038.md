# ST038 检查账户机构是否可匹配到限额场景配置

## 步骤描述

1.获取账户开立行行号：根据{账号}查询【账户信息】获取$账户开立行行号$
2.获取场景限额编码：根据[账户开立行行号]查询【限额控制配置表】获取$启用标志$等于"Y-启用"的$限额场景编码$
3.获取上级机构号：若[限额场景编码]为空，则跳转至子步骤《获取上级机构集合》，否则返回[限额场景编码]
4.获取上级机构集合：根据[账户开立行行号]查询【机构信息表】获取[上级机构集合]
5.检查上级机构匹配的限额场景：按照[上级机构集合]中的$机构层级$从大到小遍历[上级机构集合]：
1.根据[上级机构集合]的$机构号$查询【限额场景定义表】获取$启用标志$等于"Y-启用"的$限额场景编码$。
2.若[限额场景编码]为空，则继续遍历下一条，否则中断本次遍历并返回[限额场景编码]。
3.结束遍历并返回[限额场景编码]为空。
