# ST102 检查账户机构是否可匹配到限额场景配置

## 步骤描述

1.获取账户开立行行号：根据{账号}查询【账户信息】获取$账户开立行行号$，{账号}唯一确定一条账户记录，查不到账户记录或查到多条账户记录时返回[错误码]“ER0048”（账户不存在）并结束本步骤

2.获取场景限额编码：根据[账户开立行行号]查询【限额控制配置表】获取$启用标志$等于"Y-启用"的$限额场景编码$；同一机构查出多条启用配置时，按[最后修改时间戳]取最近维护的一条配置的$限额场景编码$

3.检查账户开立行是否匹配到限额场景：若[限额场景编码]为空，则跳转至子步骤《获取上级机构集合》，否则返回[限额场景编码]

4.获取上级机构集合：根据[账户开立行行号]查询【机构信息表】取得本机构的$归属上级机构号$，再按该[归属上级机构号]查询其$归属上级机构号$，如此沿归属上级机构号逐级向上，直到查不到归属上级机构号为止；把逐级取得的全部上级机构作为[上级机构集合]，不包含账户开立行自身；查不到机构记录或没有取到任何上级机构时，[上级机构集合]为空，子步骤5 遍历零次并返回[限额场景编码]为空

5.检查上级机构匹配的限额场景：按照[上级机构集合]中的$机构层级$从高到低（总行、分行、支行）遍历[上级机构集合]：

1.根据[上级机构集合]的$机构号$查询【限额控制配置表】获取$启用标志$等于"Y-启用"的$限额场景编码$；同一机构查出多条启用配置时，按[最后修改时间戳]取最近维护的一条配置的$限额场景编码$。

2.若[限额场景编码]为空，则继续遍历下一条，否则中断本次遍历并返回[限额场景编码]。
3.结束遍历并返回[限额场景编码]为空。

## 失败处理

按{账号}查询【账户信息】查不到账户记录或查到多条账户记录时，本步骤返回错误码“ER0048”（账户不存在）并结束本步骤；除该情形外本步骤无业务失败场景，失败仅由技术异常传播表达。
