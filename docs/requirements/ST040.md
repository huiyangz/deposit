# ST040 检查限额

## 步骤描述

1.获取限额控制值：根据[限额场景编码]查询【限额控制配置】获取对应的$限额控制金额$和$限额控制笔数$
2.检查限额：若[限额累计金额]大于[限额控制金额]或[限额累计笔数]大于[限额控制笔数]，则返回限额检查结果为“超限”，否则返回限额检查结果为“未超限”。

## 输入

| 字段名 | 类型 | 标记 | 来源实体 | 说明 |
|--------|------|------|----------|------|
| limitSceneNo | java.lang.String | 必填 | | 限额场景编码 |
| limitSumAmt | java.math.BigDecimal | 必填 | | 限额累计金额 |
| 否 | java.lang.Integer | 必填 | | 限额累计笔数 |

## 输出

| 字段名 | 类型 | 标记 | 来源实体 | 说明 |
|--------|------|------|----------|------|
| limitCtrlAmt | java.math.BigDecimal | 非必填 | 限额控制配置（RB_LIMIT_CTRL_CONF） | 限额控制金额 |
| limitCtrlNum | java.lang.Integer | 非必填 | 限额控制配置（RB_LIMIT_CTRL_CONF） | 限额控制笔数 |
| limitSumAmt | java.math.BigDecimal | 非必填 | 限额累计信息表（RB_LIMIT_SUM_INFO） | 限额累计金额 |
| 否 | java.lang.Integer | 非必填 | 限额累计信息表（RB_LIMIT_SUM_INFO） | 限额累计笔数 |
