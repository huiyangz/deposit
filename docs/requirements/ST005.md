# ST005 检查支取账户限额

## 步骤描述

1.匹配限额场景：根据 {客户号}、{账号}、{限额因子} 访问业务组件《检查限额组件》的任务《检查限额》的步骤《匹配限额场景》，获取[执行结果]
2.检查执行结果：若[执行结果]为“已匹配到限额场景”，则继续执行，否则返回检查结果为“通过”。
3.检查机构匹配的限额场景配置：根据{账号}访问业务组件《检查限额组件》的任务《检查限额》的步骤《检查账户机构是否可匹配到限额场景配置》获取[限额场景编码]，若[限额场景编码]为空，则返回检查结果为“通过”，否则继续执行。
4.检查有效的限额场景配置：根据[限额场景编码],{交易日期}，{交易时间}访问业务组件《检查限额组件》的任务《检查限额》的步骤《检查限额场景配置是否有效》获取[限额场景编码]，若[限额场景编码]为空，则返回检查结果为“通过”，否则继续执行。
5.检查限额场景编码：根据[限额场景编码]、{账号}、{客户号}，访问业务组件《检查限额组件》的任务《检查限额》的步骤《获取限额场景编码》获取[限额场景编码]，若[限额场景编码]为空，则返回检查结果为“通过”，否则继续执行。
6.获取累计限额：根据[限额场景编码]、{账号}、{客户号}，访问业务组件《检查限额组件》的任务《检查限额》的步骤《获取累计限额》获取$限额累计金额$，$限额累计笔数$
7.计算限额累计值：根据{账号}、{客户号}、{交易金额}、[限额场景编码]访问业务组件《检查限额组件》的任务《检查限额》的步骤《计算限额累计金额》
8.检查限额：根据[限额场景编码]、[限额累计金额]、[限额累计笔数]访问业务组件《检查限额组件》的任务《检查限额》的步骤《检查限额》获取[限额检查结果]
9.检查限额检查结果：若[限额检查结果]为“未超限”，则跳转至子步骤《根据累计情况判断限额更新分支》，否则继续执行。
10.获取超限处理方式：根据[限额场景编码]访问业务组件《检查限额组件》的任务《检查限额》的步骤《处理限额》获取[检查结果]
11.处理限额超限：a.若[检查结果]为“拒绝”，则返回[错误码]“ER0058”b.若[检查结果]为“授权”，则返回[授权标志]为“需授权”并等待授权。c.若[检查结果]为“提示”，则返回检查结果为“超限，但可继续交易”
12.根据累计情况判断限额更新分支：a.若[限额检查结果]为“未超限”，且[限额累计金额]大于0或者[限额累计笔数]大于0，则继续执行b.若[限额检查结果]为“未超限”，且[限额累计金额]等于0或者[限额累计笔数]等于0，则跳转至子步骤《登记累计限额》
13.更新累计限额：根据[限额场景编码]、{客户号}、{账号}，访问业务组件《检查限额组件》的任务《检查限额》的步骤《更新累计限额》
14.登记累计限额：根据[限额场景编码]、{客户号}、{账号}，访问业务组件《检查限额组件》的任务《检查限额》的步骤《登记累计限额》
