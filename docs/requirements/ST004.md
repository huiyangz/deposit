# ST004 检查账户通兑信息

## 步骤描述

1.获取账户开立行行号和通兑标志：根据{账号}查询【账户信息】获取$账户开立行行号$、$通兑标志$
2.检查开立行与交易机构一致性：若[账户开立行行号]不等于{交易机构}，则继续执行，否则返回检查结果为“通过”
3.检查通兑标志：a.若[通兑标志]等于“D-指定机构通兑”，则跳转至子步骤《获取指定通兑机构》
b.若[通兑标志]等于“F-分行间通兑”,则跳转至子步骤《获取开立行的机构层级与上级机构》
c.若[通兑标志]等于“N-不允许通兑”，则返回[错误码]“ER0072”
d.若[通兑标志]等于“Y-全行通兑”,则返回检查结果为“通过”
e.其他情况，则返回[错误码]“ER0071”
4.获取指定通兑机构：根据{账号}查询【账户信息】获取$通兑机构$
5.检查指定通兑机构：若{交易机构}在{通兑机构}氛围内，则返回检查结果为“通过”，否则返回[错误码]“ER0073”
6.获取开立行的机构层级与上级机构：根据{账户开立行行号}查询【机构信息】获取开户行的$机构层级代码$、$归属上级机构号$
7.获取交易行的机构层级与上级机构：根据{交易机构}查询【机构信息】获取交易行的$机构层级代码$、$归属上级机构号$
8.赋值开户机构的管辖分行：a. 若账户的[账户开立行行号]的[机构层级代码]等于”2-支行“，则赋值[开户机构的管辖分行]为[归属上级机构号];
b.若账户的[账户开立行行号]的[机构层级代码]等于“1-分行”，则赋值[开户机构的管辖分行]为[账户开立行行号]
9.赋值交易机构的管辖分行：a. 若{交易机构}的[机构层级代码]等于”2-支行“，则赋值交易机构的[交易机构的管辖分行]为[归属上级机构号];
b. 若{交易机构}的[机构层级代码]等于“1-分行”，则赋值交易机构的[交易机构的管辖分行]为[账户开立行行号]
10.检查管辖机构一致性：若[开户机构的管辖分行]等于[交易机构的管辖分行]，则返回检查结果为“通过”，否则返回[错误码]“ER0073”
