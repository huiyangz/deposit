# ST098 检查账户用途

## 步骤描述

1.检查资本向下人民币账户的核准件编号：{币种}为“人民币”且{账户用途}为"资本项下"时，若{核准件编号}为空，则返回[错误码]“ER0012”，否则继续执行。
2.检查资本向下人民币账户的账户属性：{币种}为“人民币”且{账户用途}为"资本项下"时，若{账户属性}为空，则返回[错误码]“ER0013”，否则继续执行。
3.检查账户属性：根据账户属性判断检查内容：
a.若{账户属性}为"基本存款账户"或"一般户"，则跳转至子步骤《检查基本户和验资户的账户用途》
b.若{账户属性}为"验资户"，则跳转至子步骤《检查临时户的账户用途》
c.若{账户属性}为"专用存款账户"，则跳转至子步骤《检查专用户的账户用途》
d.若{账户属性}为上述四类以外的其它取值（含"临时存款账户"）或为空，则返回检查结果为"通过"。

4.检查基本户和验资户的账户用途：若{账户属性}为"基本存款账户"或"一般户"且{账户用途}不为空且不为”无特殊用途“，则返回[错误码]“ER0014”，否则返回检查结果为“通过”。

5.检查临时户的账户用途：若{账户属性}为“验资户”且{账户用途}不等于“注册验资”或“增资验资”或“无特殊用途”，则返回[错误码]“ER0015”，否则返回检查结果为“通过”。

6.检查专用户的账户用途：若{账户属性}为“专用存款账户”且{账户用途}不等于"预算单位专用","非预算单位专用"，则返回[错误码]“ER0016”，否则返回检查结果为“通过”。
