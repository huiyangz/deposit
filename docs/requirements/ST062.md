# ST062 检查是否存在现金止付限制

## 步骤描述

1.获取账户限制信息：根据{账号}、$限制状态$等于"A-生效"查询【账户限制信息】获取[账户限制信息]（集合），必须包括$账户限制类型$、$限制编号$
2.获取账户限制类型信息：遍历[账户限制信息]（集合）：1）根据$账户限制类型$，$状态$等于"A-生效"查询【限制类型表】获取$借贷方控制标志$、$现金标志$2）若$借贷方控制标志$等于"D-禁止借方"且$现金标志$等于"N-不允许现金"，则返回现金止付标志为“是”，并结束本次遍历，否则继续遍历下一条结束本次遍历，返回现金止付标志为“否”
