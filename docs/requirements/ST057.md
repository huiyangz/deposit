# ST057 检查支取交易类型

## 步骤描述

1.获取现金支取交易类型：根据{交易类型}查询【交易类型定义】获取对应的$借贷标志$、$现金交易标志$、$冲正交易标志$
2.检查交易类型：若[借贷标志]为“D-借方”，且[现金交易标志]为“Y是”，且[冲正交易标志]为“N否”，则继续执行，否则返回[错误码]“ER0067”

## 输入

| 字段名 | 类型 | 标记 | 来源实体 | 说明 |
|--------|------|------|----------|------|
| tranType | com.dcits.depsit.enums.TranType | 必填 | | 交易类型 |

## 输出

| 字段名 | 类型 | 标记 | 来源实体 | 说明 |
|--------|------|------|----------|------|
| crDrInd | com.dcits.depsit.enums.CrDrInd | 非必填 | | 借贷标志 |
| cashTranFlag | java.lang.String | 非必填 | | 现金交易标志 |
| reversal | java.lang.String | 非必填 | | 冲正交易标志 |
