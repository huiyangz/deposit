# ST057 检查限制优先级

## 步骤描述

1.获取交易的限制级别：根据{交易类型}查询【交易定义信息】获取交易的$限制级别$
2.获取限制的冻结级别：根据{账户限制类型}查询【限制类型定义信息】获取限制的$冻结级别$
3.检查限制优先级：若交易的[限制级别]高于账户限制类型对应的[冻结级别]，则返回检查结果“不检查限制”，否则返回检查结果为“继续检查”

## 输入

| 字段名 | 类型 | 标记 | 来源实体 | 说明 |
|--------|------|------|----------|------|
| tranType | com.dcits.deposit.enums.TranType | 必填 | | 交易类型 |
| restraintType | com.dcits.deposit.enums.RestraintType | 必填 | | 账户限制类型 |

## 输出

| 字段名 | 类型 | 标记 | 来源实体 | 说明 |
|--------|------|------|----------|------|
| resPriority | java.lang.String | 非必填 | 交易类型定义表（RB_TRAN_DEF） | 冻结级别 |
| resPriority | java.lang.String | 非必填 | 存款限制类型表（RB_RESTRAINT_TYPE） | 冻结级别 |

## 相关枚举

| 枚举 | 别名 |
|------|------|
| 交易类型 | 交易类型、输入数据-交易类型 |
| 限制类型 | 账户限制类型、输入数据-账户限制类型 |

## 补充说明

- {交易类型,输入数据-交易类型}取值来源于代码[交易类型]，对应枚举类-类名：com.dcits.deposit.enums.TranType
- {账户限制类型,输入数据-账户限制类型}取值来源于代码[限制类型]，对应枚举类-类名：com.dcits.deposit.enums.RestraintType
