# ST025 检查法透账户支取限制

## 步骤描述

1.获取不收不付标志：根据 {账号} 访问业务组件《检查限制组件》的《检查账户限制》任务的步骤《检查是否存在不收不付限制》获取[不收不付标志]
2.检查不收不付限制：若[不收不付标志]等于“是”，则返回[错误码]“ER0059”，否则继续执行
3.获取止付标志：根据{账号}访问业务组件《检查限制组件》的任务《检查账户限制》的步骤《检查是否存在止付限制》，获取 [止付标志]
4.检查止付标志：若[止付标志]等于“是”，则返回[错误码]“ER0065”，否则继续执行
5.获取有权机关冻结标志：根据 {账号}访问业务组件《检查限制组件》的任务《检查账户限制》的步骤《检查有权机关冻结限制》，获取 [有权机关冻结标志]
6.检查有权机关冻结标志：若[有权机关冻结标志]等于“是”，则返回[错误码]“ER0066”，否则返回检查结果为“通过”
