# ST052 检查是否存在转账止付限制

## 步骤描述

1.获取账户限制信息：根据{账号}、$限制状态$等于"A-生效"查询【账户限制信息】获取[账户限制信息]，必须包括$账户限制类型$、$限制编号$
2.获取账户限制类型类型：根据[账户限制信息]中的$账户限制类型$查询【限制类型表】获取$状态$等于"A-生效"的$借贷方控制标志$、$转账标志$
3.检查是否存在转账止付限制：若是限制类型对应的$借贷方控制标志$等于"D-禁止借方"且$转账标志$等于"N-不允许转账"，则返回转账止付标志为“是”，否则返回转账止付标志为“否”。
