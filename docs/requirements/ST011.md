# ST011 检查支取密码状态

## 步骤描述

1.获取密码状态：根据{账号}、{密码类型}为“支取密码”查询【账户密码信息】获取$密码状态$
2.检查密码状态：若[密码状态]为“L-锁定”，则返回[错误码]“ER0079”，否则跳转至步骤《验证密码》

## 输入

| 字段名 | 类型 | 标记 | 来源实体 | 说明 |
|--------|------|------|----------|------|
| baseAcctNo | java.lang.String | 必填 | | 账号 |
| pwdType | com.dcits.deposit.enums.PwdType | 必填 | | 密码类型 |

## 输出

| 字段名 | 类型 | 标记 | 来源实体 | 说明 |
|--------|------|------|----------|------|
| passwordStatus | com.dcits.deposit.enums.PasswordStatus | 非必填 | 对公账户密码表（RB_BUS_PASSWORD） | 密码状态 |

## 相关枚举

| 枚举 | 别名 |
|------|------|
| 密码类型 | 密码类型、输入数据-密码类型 |
| 密码状态 | 密码状态、输出数据-密码状态 |

- {密码状态,输出数据-密码状态}取值来源于代码[密码状态]，对应枚举类-类名：com.dcits.deposit.enums.PasswordStatus
