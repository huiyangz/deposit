# ST112 检查限制豁免

## 步骤描述

1.获取渠道的柜面标志：根据{渠道类型}按【渠道类型定义表】的渠道匹配唯一一条记录，获取其对应的$柜面标志$；查不到记录时，该渠道的柜面标志按“N-否”处理

2.获取限制控制明细：根据{账户限制类型}查询【限制控制明细表】获取其对应$状态$等于“A-生效”的[限制控制明细信息]，包括$产品类型$、$多交易类型$、$渠道集合$、$摘要码$、$限制机构范围$、$柜面标志$；未查询到$状态$为“A-生效”的限制控制明细时，账户限制类型对应的柜面标志按“N-否”处理；查询到多条时，只要其中任一条的柜面标志为“Y-是”即按“Y-是”处理，全部为“N-否”时按“N-否”处理；[限制控制明细信息]取全部查询结果

3.检查柜面标志：若{渠道类型}对应的[柜面标志]等于"Y-是"且账户限制类型对应的[柜面标志]等于“Y-是”，则跳转至子步骤《检查柜面渠道的豁免信息》，否则跳转至子步骤《检查非柜面渠道的豁免信息》
4.检查柜面渠道的豁免信息：若[限制控制明细信息]中存在{交易类型}、{摘要码}、{产品类型}同时匹配的信息，则返回检查结果“不检查限制”，否则返回检查结果“需检查限制”。
5.检查非柜面渠道的豁免信息：{渠道类型}对应的[柜面标志]与账户限制类型对应的[柜面标志]未同时等于“Y-是”时，若[限制控制明细信息]中存在{交易类型}、{摘要码}、{产品类型}同时匹配的信息，则返回检查结果“豁免”，否则返回检查结果“不豁免”。
