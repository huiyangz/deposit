# BR008 设置自贸区种类

## 目标与范围

本任务目标：把"设置自贸区种类"规则（BR008，断言类）的已确认业务定义整理为可验证 Spec——依据客户类型、税收居民标识、境内境外标志，确定账户属性（自贸区种类）的取值，并作为规则返回值返回。

范围内：

- 源需求"规则描述"明确列出的 5 条判定分支（a、b、c、d、e）及其触发条件、预期返回值。
- 上述分支涉及的输入字段、输出字段与取值映射（含字段类型、必填标记、枚举绑定、来源实体）。

不在范围内：

- 源需求未列出输入组合的取值（不推断默认值，不作为验收项，见"验收范围与明确不覆盖的事项"）。
- 输入数据的采集、来源系统取数与字段合法性校验。
- 账户属性写库到 `RB_BUS_ACCT`、报文/接口展示、其他规则或平台服务调用、异常与错误码处理。

## Requirements

### Requirement: REQ-001 个人客户按税收居民标识确定账户属性

来源：`docs/requirements/BR008.md` 规则描述 a、b

当 {客户类型} 等于 "100-个人" 时，系统 SHALL 仅依据 {税收居民标志} 确定 [自贸区种类]：{税收居民标志} 等于 "1-中国税收居民" 或 "3-既是中国税收居民又是其他国家（地区）税收居民" 时，返回 `acctNatureNo` 等于 "3605"；{税收居民标志} 等于 "2-非中国税收居民" 时，返回 `acctNatureNo` 等于 "3606"。该分支 MUST NOT 受 {境内境外标志} 取值影响。

#### Scenario: REQ-001-S01 个人且中国税收居民

- **GIVEN** `clientType` 等于 "100"（`com.dcits.depsit.enums.ClientType.VALUE_100`，个人）；`taxResidentFlag` 等于 "1"（`com.dcits.depsit.enums.TaxResidentFlag.VALUE_1`，中国税收居民）；`isIndividual`、`inlandOffshore` 取示例值（源需求未定义取值域且不参与本分支判定，不作为断言依据）
- **WHEN** 调用本规则并传入上述入参
- **THEN** 规则返回 `acctNatureNo` 等于 "3605"（`com.dcits.depsit.enums.AcctNatureNo.VALUE_3605`，自贸区内个人自由贸易账户FTI；源需求记法 "FTI-区内个人自由贸易账户"）

#### Scenario: REQ-001-S02 个人且既是中国税收居民又是其他国家（地区）税收居民

- **GIVEN** `clientType` 等于 "100"；`taxResidentFlag` 等于 "3"（`com.dcits.depsit.enums.TaxResidentFlag.VALUE_3`）；`isIndividual`、`inlandOffshore` 取示例值
- **WHEN** 调用本规则并传入上述入参
- **THEN** 规则返回 `acctNatureNo` 等于 "3605"（`AcctNatureNo.VALUE_3605`，自贸区内个人自由贸易账户FTI）

#### Scenario: REQ-001-S03 个人且非中国税收居民

- **GIVEN** `clientType` 等于 "100"；`taxResidentFlag` 等于 "2"（`com.dcits.depsit.enums.TaxResidentFlag.VALUE_2`，非中国税收居民）；`isIndividual`、`inlandOffshore` 取示例值
- **WHEN** 调用本规则并传入上述入参
- **THEN** 规则返回 `acctNatureNo` 等于 "3606"（`AcctNatureNo.VALUE_3606`，自贸区内境外个人自由贸易账户FTF；源需求记法 "FTF-区内境外个人自由贸易账户"）

#### Scenario: REQ-001-S04 个人分支不受境内境外标志影响

- **GIVEN** `clientType` 等于 "100"；`taxResidentFlag` 等于 "1"；`inlandOffshore` 等于 "N"（个人分支的判定条件不含该字段）
- **WHEN** 调用本规则并传入上述入参
- **THEN** 规则仍返回 `acctNatureNo` 等于 "3605"（与 `inlandOffshore` 取 "Y" 时结果一致）

- **WHEN** 调用本规则并传入上述入参
- **THEN** 规则返回 `acctNatureNo` 等于 "3603"（`com.dcits.depsit.enums.AcctNatureNo.VALUE_3603`，自贸区内机构自由贸易账户FTE；源需求记法 "FTE-区内机构自由贸易账户"）

#### Scenario: REQ-002-S02 对公且境外

- **THEN** 规则返回 `acctNatureNo` 等于 "3604"（`AcctNatureNo.VALUE_3604`，境外机构自由贸易账户FTN；源需求记法 "FTN-境外机构自由贸易账户"）

#### Scenario: REQ-002-S03 对公分支不受税收居民标识影响

- **THEN** 规则仍返回 `acctNatureNo` 等于 "3603"（与 `taxResidentFlag` 取 "1" 或 "3" 时结果一致）

### Requirement: REQ-003 同业客户按境内境外标志确定账户属性

- **WHEN** 调用本规则并传入上述入参

## 验收范围与明确不覆盖的事项

1. 合法但源需求未定义的输入组合（无对应分支与预期结果，本 Spec 不推断默认值，也不作为验收项）：
   - {客户类型}="200-对公" 且 {境内境外标志} 不是 "Y" 或 "N"（含为空）；
   - {客户类型}="300-同业" 且 {境内境外标志} 不是 "N"（含 "Y" 或为空）；
   - {客户类型} 取 `ClientType` 中未在规则描述出现的值（如 "600-内部客户"）；
   - 个人分支中 {税收居民标志} 为枚举外取值或为空时的结果（对公、同业分支已明确不受该字段影响）。
2. 字段作用未定义：`isIndividual`（对私客户标志）在输入清单中标为必填，但规则描述 a–e 未引用该字段，源需求未定义其取值对结果的影响；本 Spec 不据此新增判定分支、校验或默认行为。
3. 取值与名称表述差异（已按本组件枚举归一，供核对）：
   - 源需求以 "FTI-区内个人自由贸易账户" 等"缩写-名称"记法书写取值，`com.dcits.depsit.enums.AcctNatureNo` 中对应项的码值为 "3605" 等；本 Spec 以枚举码值作为规则返回的具体值，两者指向同一账户属性。
   - 客户类型名称：源需求写 "200-对公"、"300-同业"，`ClientType` 的对应注释为"公司"、"金融机构"，码值 200/300 唯一对应。
   - 税收居民标识名称：源需求写 "2-非中国税收居民"，`TaxResidentFlag.VALUE_2` 注释为"非居民"，码值 "2" 唯一对应。
   - 同一对象在规则描述与输入清单中名称不同：`{税收居民标志}` ↔ `taxResidentFlag`、`{境内境外标志}` ↔ `inlandOffshore`，按语义唯一对应。
4. 不覆盖：输入字段的采集与合法性校验、账户属性写库到 `RB_BUS_ACCT`、报文/接口展示、其他规则或平台服务调用、异常与错误码处理（规则以返回值表达结果）。源需求均未要求，本 Spec 不新增。
5. 空值语义：四个输入在源需求中均标必填，任一输入为空时的结果源需求未定义，故不列入验收；输出字段的"非必填"标记未附额外业务含义。
6. 本 Spec 是测试设计依据：场景用于推导断言，不代表已生成的测试用例，也不是测试执行结果。
