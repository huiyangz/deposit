# ST041 处理限额

## 目标与范围

本 Spec 定义交易执行步骤「处理限额」（ST041）的输入输出契约与行为。步骤以必填输入 限额场景编码（limitSceneNo）查询【限额控制配置】（RB_LIMIT_CTRL_CONF），取得对应配置记录的 处理方式（dealFlow），并按处理方式（拒绝/提醒/授权）返回检查结果。

范围仅覆盖需求文档「步骤描述」「输入」「输出」「相关枚举」「补充说明」中已确认的内容。限额控制配置查询的记录定位方式、查询无记录、处理方式为空、limitSceneNo 未提供等未定义情形见「待确认事项」，不作为已确认条款写入验收预期。

## Requirements

### Requirement: REQ-001 查询限额控制配置并按处理方式返回检查结果
来源：需求「步骤描述」条目 1、2；「输入」「输出」表；「相关枚举」「补充说明」；工程枚举 `com.dcits.deposit.enums.DealFlow`、EO `RbLimitCtrlConfEO`。

系统 SHALL 以必填输入 limitSceneNo（java.lang.String，限额场景编码）为依据，查询【限额控制配置】（RB_LIMIT_CTRL_CONF）获取对应配置记录的 处理方式（dealFlow），并按处理方式输出检查结果，三者分支互斥：

- 处理方式为"拒绝"时，输出 dealFlow 为枚举 `DealFlow.B`，返回检查结果为"拒绝"；
- 处理方式为"提醒"时，输出 dealFlow 为枚举 `DealFlow.D`，返回检查结果为"提醒"；
- 处理方式为"授权"时，输出 dealFlow 为枚举 `DealFlow.A`，返回检查结果为"授权"。

本步骤正常完成（StepResult.succeed=true，errorCode 与 errorMessage 为空），除输出 dealFlow（处理方式）外不产生其它业务输出。

#### Scenario: REQ-001-S01 处理方式为"拒绝"时返回检查结果"拒绝"
- **GIVEN** 限额控制配置（RB_LIMIT_CTRL_CONF）中存在 limitSceneNo 为 "LMT1001" 的配置记录，其处理方式为"拒绝"（对应枚举值 B）
- **WHEN** 本步骤以输入 limitSceneNo="LMT1001" 执行
- **THEN** 本步骤输出 dealFlow 为 `DealFlow.B`，返回检查结果为"拒绝"，步骤成功（succeed=true，errorCode 与 errorMessage 为空）

#### Scenario: REQ-001-S02 处理方式为"提醒"时返回检查结果"提醒"
- **GIVEN** 限额控制配置（RB_LIMIT_CTRL_CONF）中存在 limitSceneNo 为 "LMT1001" 的配置记录，其处理方式为"提醒"（对应枚举值 D）
- **WHEN** 本步骤以输入 limitSceneNo="LMT1001" 执行
- **THEN** 本步骤输出 dealFlow 为 `DealFlow.D`，返回检查结果为"提醒"，步骤成功（succeed=true，errorCode 与 errorMessage 为空）

#### Scenario: REQ-001-S03 处理方式为"授权"时返回检查结果"授权"
- **GIVEN** 限额控制配置（RB_LIMIT_CTRL_CONF）中存在 limitSceneNo 为 "LMT1001" 的配置记录，其处理方式为"授权"（对应枚举值 A）
- **WHEN** 本步骤以输入 limitSceneNo="LMT1001" 执行
- **THEN** 本步骤输出 dealFlow 为 `DealFlow.A`，返回检查结果为"授权"，步骤成功（succeed=true，errorCode 与 errorMessage 为空）

## 待确认事项

- **TBD-1（关联 REQ-001）**：限额控制配置表主键为（限额机构编码、限额场景编码），需求仅声明输入 limitSceneNo。按限额场景编码查询时，若多个机构存在同一场景编码的配置记录，可能命中多条记录。需求未说明如何定位唯一配置记录（查询方式为 `findByPrimaryKey(limitBranchId, limitSceneNo)` 还是 `findByEo(limitSceneNo)`、限额机构编码从何处取得、是否约定唯一命中），需确认。
- **TBD-2（关联 REQ-001）**：限额控制配置中不存在所给限额场景编码的记录时，本步骤行为未定义（是否返回空检查结果、是否业务失败及对应错误码），需求未声明，需确认。
- **TBD-3（关联 REQ-001）**：配置记录存在但处理方式（dealFlow）为空时，返回检查结果未定义，需确认。
- **TBD-4（关联 REQ-001）**：limitSceneNo 标记"必填"；调用方未提供（null 或空白）时，是否由本步骤自行校验并失败，需求未声明，需确认调用方保证提供或步骤需校验。
