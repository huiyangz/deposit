# BR004 计算账户利率

## 目标与范围

本任务定义存款业务组件中「计算账户利率」规则（规则类型：计算类）的行为契约：根据调用方提供的产品利率与账户级利率浮动要素，按需求规定的优先级唯一确定并返回执行利率。

范围内：

- 由 `prodRate`（产品利率）与 `acctSpreadRate`（账户利率浮动百分点）、`acctPercentRate`（账户利率浮动百分比）、`acctFixedRate`（账户固定利率）三个可选账户级浮动要素，按 `a → b → c → d` 的优先级计算 `realRate`（执行利率）。
- 输入的可空语义（空与 0 在条件判断中等价）及浮动百分比的输入口径。
- 四种取值分支各自的计算公式与分支互斥性。

不在范围内：

- 不定义 `prodRate`、`acctSpreadRate`、`acctPercentRate`、`acctFixedRate` 的来源与获取方式（需求「来源实体」列为空，由调用方直接提供）。
- 不定义结果的持久化、入账、利息计结、账户状态变更等副作用——本规则为纯计算，不产生副作用。
- 不定义精度与舍入方式（需求未规定，见「验收范围与明确不覆盖的事项」）。
- 不定义输入缺失 `prodRate` 时的异常行为（需求未规定）。
- 不定义超过以上四个分支之外的其他浮动要素叠加方式（需求未要求）。

## 输入、输出及依赖契约

输入：

| 字段名 | 类型 | 必填性 | 空值语义 | 说明 |
|--------|------|--------|----------|------|
| `acctSpreadRate` | java.math.BigDecimal | 非必填 | 空与 0 在分支判断中等价 | 账户利率浮动百分点 |
| `acctPercentRate` | java.math.BigDecimal | 非必填 | 空与 0 在分支判断中等价 | 账户利率浮动百分比，以小数比率传入（上浮 10% 记 0.1） |
| `acctFixedRate` | java.math.BigDecimal | 非必填 | 空与 0 在分支判断中等价 | 账户固定利率 |
| `prodRate` | java.math.BigDecimal | 必填 | 需求未定义其缺失时的行为 | 产品利率 |

输出：

| 字段名 | 类型 | 标记 | 说明 |
|--------|------|------|------|
| `realRate` | java.math.BigDecimal | 非必填 | 执行利率。标记反映实体字段本身可空，不代表规则可能不产出结果；在输入满足本 Spec 前提时，本规则恒返回该值 |

依赖契约：

- 组件内步骤调用：不适用。本规则不调用其他组件步骤，无调用位置、参数传递与执行结果短路要求。
- 跨步骤数据传递：不适用。四个输入均由调用方在同一次计算中提供，「来源实体」列为空，无需跨步骤取数。
- 外部依赖（数据库、外部系统、限额/黑名单/限制组件等）：不适用。
- 计算口径：按需求 a 为加法、b 为「产品利率 ×（1 + 浮动百分比）」的乘法、c/d 为直接取值；三种口径互斥，不叠加、不组合。

## Requirements

### Requirement: REQ-001 按优先级分支确定执行利率
来源：`docs/requirements/BR004.md`「规则描述」a、b、c、d。

系统 SHALL 按下述优先级顺序判定并计算执行利率：a 优先于 b，b 优先于 c，c 优先于 d；命中首个成立的条目即返回，不再评估后续条目：
- a：`acctSpreadRate` 不等于 0 时，`realRate` = `prodRate` + `acctSpreadRate`；
- b：`acctSpreadRate` 为 0 或为空，且 `acctPercentRate` 不等于 0 时，`realRate` = `prodRate` × (1 + `acctPercentRate`)；
- c：`acctSpreadRate` 与 `acctPercentRate` 均为 0 或为空，且 `acctFixedRate` 不等于 0 时，`realRate` = `acctFixedRate`；
- d：`acctSpreadRate`、`acctPercentRate`、`acctFixedRate` 均为 0 或为空时，`realRate` = `prodRate`。

系统 SHALL 将「空」与「0」在各分支的前置条件中等价处理，即输入为空时按 0 参与判断。

#### Scenario: REQ-001-S01 浮动百分点非 0 时按产品利率加浮动百分点返回
- **GIVEN** `prodRate` = 0.03，`acctSpreadRate` = 0.005，`acctPercentRate` = 0，`acctFixedRate` = 0
- **WHEN** 调用计算账户利率
- **THEN** 返回 `realRate` = 0.035（= 0.03 + 0.005），且不应用「产品利率 ×（1 + 浮动百分比）」或固定利率口径

#### Scenario: REQ-001-S02 浮动百分点为 0 或空且浮动百分比非 0 时按乘积口径返回
- **GIVEN** `prodRate` = 0.03，`acctSpreadRate` = 0，`acctPercentRate` = 0.1，`acctFixedRate` = 0
- **WHEN** 调用计算账户利率
- **THEN** 返回 `realRate` = 0.033（= 0.03 × (1 + 0.1)）

#### Scenario: REQ-001-S03 前两项为 0 或空且固定利率非 0 时返回固定利率
- **GIVEN** `prodRate` = 0.03，`acctSpreadRate` = 0，`acctPercentRate` = 0，`acctFixedRate` = 0.025
- **WHEN** 调用计算账户利率
- **THEN** 返回 `realRate` = 0.025，且结果与 `prodRate` 取值无关

#### Scenario: REQ-001-S04 三个浮动要素均为 0 或空时返回产品利率
- **GIVEN** `prodRate` = 0.03，`acctSpreadRate` = 0，`acctPercentRate` = 0，`acctFixedRate` = 0
- **WHEN** 调用计算账户利率
- **THEN** 返回 `realRate` = 0.03（等于 `prodRate`）

#### Scenario: REQ-001-S05 多种浮动要素并存时按最高优先级取一种口径，不叠加
- **GIVEN** `prodRate` = 0.03，`acctSpreadRate` = 0.005，`acctPercentRate` = 0.1，`acctFixedRate` = 0.025
- **WHEN** 调用计算账户利率
- **THEN** 返回 `realRate` = 0.035（仅命中条目 a；禁止叠加为 0.03 + 0.005 + 0.03×0.1 等组合值，也禁止返回 0.025 或 0.033）

#### Scenario: REQ-001-S06 浮动百分点为负值（不等于 0）时仍命中条目 a
- **GIVEN** `prodRate` = 0.03，`acctSpreadRate` = -0.005，`acctPercentRate` = 0.1，`acctFixedRate` = 0
- **WHEN** 调用计算账户利率
- **THEN** 返回 `realRate` = 0.025（= 0.03 + (-0.005)）；命中条目 a 的条件仅为「不等于 0」，不受取值正负影响

### Requirement: REQ-002 空值与零值在分支判断中等价
来源：`docs/requirements/BR004.md`「规则描述」b、c、d（「为 0 或为空」表述）及「输入」表三个非必填标记。

系统 SHALL 在条目 b、c、d 的前置条件判断中，将输入的「为空」视为「等于 0」，二者不产生分支走向差异；`acctSpreadRate`、`acctPercentRate`、`acctFixedRate` 三个输入均允许不提供（非必填），未提供时按 0 参与判断。

#### Scenario: REQ-002-S01 浮动百分点为空、浮动百分比非 0 时命中条目 b
- **GIVEN** `prodRate` = 0.03，`acctSpreadRate` = 空（null），`acctPercentRate` = 0.1，`acctFixedRate` = 空（null）
- **WHEN** 调用计算账户利率
- **THEN** 返回 `realRate` = 0.033；即空值 `acctSpreadRate` 与 0 等价，不因取值缺失跳过条目 b

#### Scenario: REQ-002-S02 显式 0 与空等价，命中条目 c
- **GIVEN** `prodRate` = 0.03，`acctSpreadRate` = 0.00，`acctPercentRate` = 空（null），`acctFixedRate` = 0.025
- **WHEN** 调用计算账户利率
- **THEN** 返回 `realRate` = 0.025；前两项分别为显式 0 与空，均满足条目 c 的「为 0 或为空」条件

#### Scenario: REQ-002-S03 三个浮动要素均为空时命中条目 d
- **GIVEN** `prodRate` = 0.03，`acctSpreadRate` = 空（null），`acctPercentRate` = 空（null），`acctFixedRate` = 空（null）
- **WHEN** 调用计算账户利率
- **THEN** 返回 `realRate` = 0.03（等于 `prodRate`）

### Requirement: REQ-003 浮动百分比输入口径为小数比率
来源：`docs/requirements/BR004.md`「规则描述」条目 b（「其中账户利率浮动百分比以小数比率传入（上浮 10% 记 0.1）」）及「输入」表 `acctPercentRate` 说明。

系统 SHALL 将 `acctPercentRate` 作为小数比率直接参与计算，即入参值 0.1 表示上浮 10%，在条目 b 中按 `prodRate` × (1 + `acctPercentRate`) 使用；系统 SHALL NOT 将该入参再作百分数换算（如除以 100）或按字面百分比数值解释。

#### Scenario: REQ-003-S01 入参 0.1 表示上浮 10% 并直接参与乘积计算
- **GIVEN** `prodRate` = 0.03，`acctSpreadRate` = 空（null），`acctPercentRate` = 0.1，`acctFixedRate` = 空（null）
- **WHEN** 调用计算账户利率
- **THEN** 返回 `realRate` = 0.033（= 0.03 × 1.1）；若再按百分数换算（0.1 → 0.001）或按 10 直接参与计算所得结果均不符合本 Spec

## 验收范围与明确不覆盖的事项

覆盖：

- 条目 a、b、c、d 四个分支各自的取值结果，以及三者并存时的优先级互斥。
- 空值与 0 在分支判断中的等价处理。
- 浮动百分比的小数比率输入口径。
- 输出字段 `realRate` 的返回值断言。

明确不覆盖（需求无依据，验收不得据此断言）：

- 精度与舍入方式：需求未规定结果的小数位、精度或舍入规则，本 Spec 不约束舍入行为，测试仅按公式的确定结果断言（如上例中的 0.035、0.033、0.025、0.03）。
- `prodRate` 缺失（未提供）时的行为与错误返回：需求未规定，本 Spec 不作断言。
- 超出四个分支的其他浮动要素组合或叠加计算：需求未要求，本 Spec 不定义。
- 结果的持久化、账户状态变更、计息或账务副作用：本规则为纯计算，需求未要求任何副作用，测试不得断言副作用发生。
- 输入的来源获取、组件间调用与跨步骤数据传递：需求「来源实体」列为空且无调用描述，本 Spec 不定义。
- 并发、幂等、性能与日志要求：需求未涉及。
