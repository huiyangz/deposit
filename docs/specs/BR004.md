# BR004 检查交易机构和基本户开户机构互斥性

- 规则类型：断言类

## 规则描述

若{交易机构}等于{账户开立行行号}且{账户属性}为”11002-一般存款账户“则返回执行结果为“不通过”，否则返回执行结果为“通过”。

## 输入

| 字段名 | 类型 | 标记 | 说明 |
|--------|------|------|------|
| tranBranch | com.dcits.deposit.enums.TranBranch | 必填 | 交易机构号 |
| acctNatureNo | java.lang.String | 必填 | 账户属性编号 |
| acctBranch | com.dcits.deposit.enums.TranBranch | 必填 | 账户开立行行号 |

## 相关枚举

| 枚举 | 别名 |
|------|------|
| 内部机构编号 | 交易机构号、账户开立行行号 |

## 提示

- {交易机构号,交易机构号}取值来源于代码[内部机构编号]，对应枚举类-类名：com.dcits.deposit.enums.TranBranch
- {账户开立行行号,账户开立行行号}取值来源于代码[内部机构编号]，对应枚举类-类名：com.dcits.deposit.enums.TranBranch
