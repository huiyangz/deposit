# ST026 设置账户状态

## 步骤描述

1.获取客户信息：根据{客户号}查询【客户信息】获取$境内境外标识$，$客户细分类型$
2.获取企业标志：若[客户细分类型]等于"一人公司","非法人企业","有字号的个体工商户","无字号的个体工商户",则赋值$企业标志$等于"是"，否则赋值$企业标志$等于"否"
3.获取账户状态：根据{账户用途},{账户属性},[企业标志],[境内境外标识]执行规则《根据核准类型设置账户状态》，获取[账户状态]
4.赋值账户状态：若[账户状态]为空值（null），则返回[错误码]“ER0063"，否则赋值账户状态为[账户状态]。
