# ST051 增加账户限制

## 步骤描述

1.获取境内境外标识：根据{客户号}查询【客户信息】（客户副本表FM_CLIENT_COPY）获取$境内境外标识$、$客户细分类型$

2.赋值企业标志：若[客户细分类型]等于"一人公司","非法人企业","有字号的个体工商户","无字号的个体工商户",则赋值[企业标志]等于"是"，否则赋值[企业标志]等于"否"
3.获取限制信息：根据{账户属性}{账户用途}[境内境外标识][企业标志]查询【企业账户属性控制配置信息】获取$限制类型$$限制期限$$限制期限类型$

4.获取系统日期：赋值[系统日期]为{runDate}

5.计算结束日期：根据[系统日期]、[限制期限类型]、[限制期限]执行规则《计算到期日期》获取并返回[结束日期]
6.检查限制类型：根据{账号}、[限制类型]、[限制期限]、[限制期限类型]、[结束日期]、[系统日期]访问《维护限制组件》的任务《增加账户限制》的步骤《检查限制类型》获取[检查结果]

7.检查检查结果：若[检查结果]为“通过”，则继续执行，否则返回[错误码]“ER0039”。

8.检查是否跨法人：根据{账号}、{交易机构}访问《维护限制组件》的任务《增加账户限制》的步骤《检查是否跨法人》获取[检查结果]
9.检查检查结果：若[检查结果]为“通过”，则继续执行，否则返回[错误码]“ER0040”。

10.检查增加限制起始日期：根据{账号}、[限制类型]、[限制期限]、[限制期限类型]、[结束日期]、[系统日期]访问《维护限制组件》的任务《增加账户限制》的步骤《检查增加限制起始日期》获取[检查结果]
11.检查检查结果：若[检查结果]为“通过”，则继续执行，否则返回[错误码]“ER0041”。

12.登记账户限制信息：根据{账号}、[限制类型]、[限制期限]、[限制期限类型]、[结束日期]、[系统日期]访问《维护限制组件》的任务《增加账户限制》的步骤《登记账户限制信息》
