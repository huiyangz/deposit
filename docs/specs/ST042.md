# ST042 检查联系人

## 步骤描述

1.获取证件类型列表：查询【证件类型定义信息】获取全量[证件类型列表]
2.检查证件类型：若{证件类型}在[证件类型列表]中，则继续执行，否则返回[错误码]"ER0036"。
3.确定是否为居民身份证：若{证件类型}为"居民身份证"，则继续执行，否则跳转至子步骤《检查电话号码长度》
4.检查证件号码长度：若{证件号码}长度为18位，则继续执行，否则返回[错误码]"ER0037"。
5.检查电话号码长度：若{电话号码}长度为11位，则返回检查结果为"通过"，否则返回[错误码]"ER0038"。

## 输入

| 字段名 | 类型 | 标记 | 来源实体 | 说明 |

| documentType | com.dcits.deposit.enums.DocumentType | 必填 | 证件类型表（FM_DOCUMENT_TYPE） | 证件类型 |
