# ST049 检查账户执行利率

## 步骤描述

1.获取产品的利率信息：根据 {产品编号}访问 业务组件《产品管理》的 业务功能《查询产品利率信息》 ，获取$产品利率$、$最大执行利率$、$最小执行利率$

2.检查账户执行利率：若[最大执行利率]或[最小执行利率]为空（未查询到产品利率信息），或者[执行利率]大于[最大执行利率]，或者小于[最小执行利率]，则返回[错误码]“ER0033”，否则继续执行。

## 输入

| 字段名 | 类型 | 标记 | 来源实体 | 说明 |
|--------|------|------|----------|------|
| realRate | java.math.BigDecimal | 必填 | | 执行利率 |
| prodNo | java.lang.String | 必填 | 产品利率信息表（MB_PROD_INT） | 产品编号 |
| intType | com.dcits.deposit.enums.IntType | 必填 | 产品利率信息表（MB_PROD_INT） | 利率类型 |

| minRate | java.math.BigDecimal | 非必填 | 产品利率信息表（MB_PROD_INT） | 最小执行利率 |
| maxRate | java.math.BigDecimal | 非必填 | 产品利率信息表（MB_PROD_INT） | 最大执行利率 |

## 输出
