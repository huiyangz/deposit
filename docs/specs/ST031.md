# ST031 计算账户执行利率

## 步骤描述

1.获取产品的产品利率：根据 {产品编号}访问 业务组件《产品管理》的 业务功能《查询产品利率信息》 ，获取 $产品利率$（取返回字段 prodIntRate）
2.计算账户执行利率：根据 {账户利率浮动百分点}、{账户利率浮动百分比}、{账户固定利率}、{产品利率}执行规则《计算账户利率》 获取 $执行利率$并返回[执行利率]

## 输入

| 字段名 | 类型 | 标记 | 来源实体 | 说明 |
|--------|------|------|----------|------|
| acctSpreadRate | java.math.BigDecimal | 非必填 | | 账户利率浮动百分点 |
| acctPercentRate | java.math.BigDecimal | 非必填 | | 账户利率浮动百分比 |
| acctFixedRate | java.math.BigDecimal | 非必填 | | 账户固定利率 |

| 产品利率 | java.math.BigDecimal | 必填 | | 产品利率 |
| prodNo | java.lang.String | 必填 | 产品利率信息表（MB_PROD_INT） | 产品编号 |

| intType | com.dcits.deposit.enums.IntType | 必填 | 利率税率阶梯表（MB_INT_MATRIX） | 利率类型 |
| intBasis | com.dcits.deposit.enums.IntBasis | 必填 | 利率税率阶梯表（MB_INT_MATRIX） | 基准利率类型 |
| baseRate | java.math.BigDecimal | 必填 | 利率税率阶梯表（MB_INT_MATRIX） | 基础汇率 |
| actualRate | java.math.BigDecimal | 必填 | 利率税率阶梯表（MB_INT_MATRIX） | 行内挂牌利率 |

## 输出

| 字段名 | 类型 | 标记 | 来源实体 | 说明 |
|--------|------|------|----------|------|
| realRate | java.math.BigDecimal | 非必填 | | 执行利率 |
