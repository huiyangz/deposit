# ST022 检查现金项目编号

## 步骤描述

1.检查现金项目编号：若{现金项目编号}为空，则返回[错误码]“ER0056”，否则返回检查结果为“通过”

## 输入

| 字段名 | 类型 | 标记 | 来源实体 | 说明 |
|--------|------|------|----------|------|
| tranType | com.dcits.deposit.enums.TranType | 必填 | | 交易类型 |
| cashItem | com.dcits.deposit.enums.CashItem | 必填 | | 现金项目编号 |

## 相关枚举

| 枚举 | 别名 |
|------|------|
| 交易类型 | 交易类型、输入数据-交易类型 |
| 现金项目 | 现金项目编号、输入数据-现金项目编号 |

## 提示

- {交易类型,输入数据-交易类型}取值来源于代码[交易类型]，对应枚举类-类名：com.dcits.deposit.enums.TranType
- {现金项目编号,输入数据-现金项目编号}取值来源于代码[现金项目]，对应枚举类-类名：com.dcits.deposit.enums.CashItem
