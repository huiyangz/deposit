# ST009 检查现金存入账户限制

## 步骤描述

1.获取账户限制信息：根据{账号}访问业务组件《检查限制组件》的任务《检查账户限制》的步骤《检查账户是否存在限制》，获取[账户限制信息]
2.检查账户限制信息：若[账户限制信息]等于空，则返回检查结果为“通过”，否则继续执行。
3.获取现金不收不付限制标志：根据{账号}访问业务组件《检查限制组件》的任务《检查账户限制》的步骤《检查是否存在现金不收不付限制》，获取[现金不收不付限制标志]
4.检查现金不收不付限制标志：若[现金不收不付限制标志]等于"是"，则返回[错误码]“ER0043”，否则继续执行。
5.获取现金止收标志：根据{账号}访问业务组件《检查限制组件》的任务《检查账户限制》的步骤《检查是否存在现金止收限制》，获取[现金止收标志]
6.检查现金止收标志：若[现金止收标志]等于"是"，则返回[错误码]“ER0044”，否则继续执行。
7.获取账户属性限制标志：根据[账户限制信息]访问业务组件《检查限制组件》的任务《检查账户限制》的步骤《检查是否存在属性限制》，获取[属性限制标志]
8.检查属性限制标志：若是[属性限制标志]等于“是”，则跳转至子步骤《获取限制豁免信息》,否则继续执行。
9.执行限制优先级检查：根据{交易类型}，[账户限制信息]的$限制类型$访问业务组件《检查限制组件》的任务《检查账户限制》的步骤《检查限制优先级》获取[检查结果]
10.根据检查结果判断限制检查分支：若[检查结果]为“不检查限制”，则返回检查结果为“通过”，否则继续执行。
11.获取限制豁免信息：根据[账户限制信息]的$限制类型$，{交易类型}，{交易渠道编号}，{产品编号}，{摘要码}访问业务组件《检查限制组件》的任务《检查账户限制》的步骤《检查限制豁免》获取[执行结果]

12.检查账户限制豁免：若[执行结果]为“豁免”，则返回检查结果为“通过”，否则返回[错误码]“ER0045”
