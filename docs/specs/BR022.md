# BR022 检查交易类型是否为现金支取

- 规则类型：断言类

## 规则描述

如果{借贷标志}为”D借方“，且{现金交易标志}为”Y是“，且{冲正交易标志}为”N否“，则返回是，否则返回否

## 输入

| 字段名 | 类型 | 标记 | 说明 |
|--------|------|------|------|
| crDrInd | com.dcits.deposit.enums.CrDrInd | 必输| 借贷标志 |
| cashTranFlag | com.dcits.deposit.enums.IndividualFlag | 必输| 现金交易标志 |
| reversal | com.dcits.deposit.enums.IndividualFlag |必输 | 冲正交易标志 |

## 输出

| 字段名 | 类型 | 标记 | 说明 |
|--------|------|------|------|
| executionResult | java.lang.String | | 执行结果 |

## 相关枚举

| 枚举 | 别名 |
|------|------|
| 借贷标志 | 借贷标志 |
| 通用标志 | 冲正交易标志、现金交易标志 |

## 提示

- {借贷标志,借贷标志}取值来源于代码[借贷标志]，对应枚举类-类名：com.dcits.deposit.enums.CrDrInd
- {现金交易标志,现金交易标志}取值来源于代码[通用标志]，对应枚举类-类名：com.dcits.deposit.enums.IndividualFlag
- {冲正交易标志,冲正交易标志}取值来源于代码[通用标志]，对应枚举类-类名：com.dcits.deposit.enums.IndividualFlag
