# ST012 更新存入后账户余额

## 步骤描述

1.获取资金入账账户的账户余额：根据{账号}查询【对公存款账户主表】获取[账户内部键值]，再根据[账户内部键值]查询【账户余额】获取$汇总金额$（依据：RbBusAcctEO 同时含 baseAcctNo 与 internalKey，IRbBusAcctBcc.findByEo 支持按账号查询，IRbBusAcctBalanceBcc 按内部键值查询与更新）

2.更新资金入账账户的账户余额：更新{账号}对应的【账户余额】的$汇总金额$=[汇总金额]+{交易金额}

## 输入

| 字段名 | 类型 | 标记 | 来源实体 | 说明 |
|--------|------|------|----------|------|
| baseAcctNo | java.lang.String | 必填 | | 账号 |
| tranAmt | java.math.BigDecimal | 必填 | | 交易金额 |

## 输出

| 字段名 | 类型 | 标记 | 来源实体 | 说明 |
|--------|------|------|----------|------|
| totalAmount | java.math.BigDecimal | 非必填 | 对公存款账户余额表（RB_BUS_ACCT_BALANCE） | 汇总金额 |
| acctAvailBal | java.math.BigDecimal | 非必填 | 对公存款账户余额表（RB_BUS_ACCT_BALANCE） | 账户可用余额 |

## 失败处理

本步骤无业务失败场景，失败仅由技术异常传播表达。
