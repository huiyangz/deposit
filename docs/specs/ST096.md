# ST096 设置账户执行利率

## 目标与范围

本任务为交易执行步骤「设置账户执行利率」。步骤正文仅含一条动作：将账户的「执行利率」属性赋值为输入参数[执行利率]（对应步骤描述“赋值账户$执行利率$为[执行利率]”）。

本次 Spec 覆盖：

- 输入参数 `realRate`（执行利率，java.math.BigDecimal，必填），作为赋值的取值来源。
- 赋值目标：账户的「执行利率」属性（正文中的「账户$执行利率$」），赋值为输入 `realRate` 的取值。
- 步骤输出参数 `realRate`（执行利率，java.math.BigDecimal，非必填）。
- 该动作为单条无条件赋值：无判定条件、无分支、无重复或条件触发。

不在本次范围（源需求未涉及或源需求已声明无此内容）：

- 业务失败场景与失败处理：源需求「## 失败处理」明确“本步骤无业务失败场景，失败仅由技术异常传播表达”，本 Spec 不生成业务失败、错误码、重试或补偿条款。
- 执行利率取值的上游来源步骤与其下游使用（本步骤只做赋值，源需求未描述取值来源步骤或赋值后的后续处理）。
- 赋值目标的落库实体与字段、所属账户要素表及其主键定位口径（源需求未声明，见“验收范围与明确不覆盖的事项”第 1 项）。
- 输入 `realRate` 未上送或为空时的行为（源需求未定义，见不覆盖事项第 2 项）。
- 数值精度、标度与舍入规则的约定（源需求未规定，见不覆盖事项第 4 项）。

## Requirements

### Requirement: REQ-001 将输入执行利率赋值给账户执行利率
来源：`docs/requirements/ST096.md` 步骤描述 1（短原文：“赋值账户$执行利率$为[执行利率]”）与输入表 `realRate`。

系统 SHALL 在执行本步骤时，将账户的「执行利率」属性赋值为输入参数 `realRate` 的取值；该赋值为无条件执行，不依赖任何取值判定，赋值完成后账户执行利率的取值为本次输入 `realRate`（覆盖该属性赋值前的既有取值）。

#### Scenario: REQ-001-S01 正常赋值并覆盖账户原有执行利率
- **GIVEN** 账户存在，其执行利率属性赋值前取值为 1.5000；输入 realRate = 3.8500
- **WHEN** 执行本步骤
- **THEN** 账户的执行利率属性取值为 3.8500，与输入 realRate 相同
- **AND** 赋值完成后不再保留赋值前的取值 1.5000（本步骤为直接赋值，而非“为空才设置”的条件赋值）

#### Scenario: REQ-001-S02 赋值为输入数值的原样传递
- **GIVEN** 输入 realRate = 3.12345（java.math.BigDecimal）
- **WHEN** 执行本步骤
- **THEN** 账户的执行利率属性取值为 3.12345，与输入 realRate 的数值相同
- **AND** 本步骤为赋值动作，源需求未声明任何取整、舍入或按标度缩放的处理，故不断言特定标度或舍入结果（见不覆盖事项第 4 项）

### Requirement: REQ-002 步骤输出执行利率
来源：`docs/requirements/ST096.md` 输出表 `realRate`（正文未显式描述返回动作，输出取值由本步骤设置的执行利率确定）。

系统 SHALL 将本步骤的输出参数 `realRate` 取值为本次设置到账户的执行利率取值，即输入 `realRate` 的取值。

#### Scenario: REQ-002-S01 输出为所设置的执行利率
- **GIVEN** 输入 realRate = 3.8500
- **WHEN** 执行本步骤并返回
- **THEN** 输出参数 realRate 取值为 3.8500，与赋给账户执行利率的取值一致
- **AND** 输出 realRate 不作为本步骤的判定或分支依据（本步骤无分支）
