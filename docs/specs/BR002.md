# BR002 计算账户利率

- 规则类型：计算类

## 规则描述

a.若{账户利率浮动百分点}不等于0，那么返回[执行利率]等于{产品利率}+{账户利率浮动百分点}；否则若{账户利率浮动百分比}不等于0，那么返回[执行利率]等于{产品利率}*（1+{账户利率浮动百分比}）；否则若{账户固定利率}不等于0，那么返回[执行利率]等于{账户固定利率}；否则（{账户利率浮动百分点}、{账户利率浮动百分比}、{账户固定利率}均为空或等于0，空值视同0）返回[执行利率]等于{产品利率}；执行利率按公式计算结果精确返回，不进行位数规整与舍入（以"否则若"链明确 a＞b＞c 优先顺序）

## 输入

| 字段名 | 类型 | 标记 | 来源实体 | 说明 |
|--------|------|------|----------|------|
| acctSpreadRate | java.math.BigDecimal | 非必填 | | 账户利率浮动百分点 |
| acctPercentRate | java.math.BigDecimal | 非必填 | | 账户利率浮动百分比 |
| acctFixedRate | java.math.BigDecimal | 非必填 | | 账户固定利率 |
| productRate | java.math.BigDecimal | 必填 | | 产品利率 |

## 输出

| 字段名 | 类型 | 标记 | 来源实体 | 说明 |
|--------|------|------|----------|------|
| realRate | java.math.BigDecimal | 必填 | | 执行利率 |

## 提示

- 可能相关的属性：账户利率浮动百分点，类型为：java.math.BigDecimal
- 可能相关的属性：账户利率浮动百分比，类型为：java.math.BigDecimal
- 可能相关的属性：账户固定利率，类型为：java.math.BigDecimal
