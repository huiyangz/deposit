# BR002 计算账户利率

- 规则类型：计算类

## 规则描述

a.若{账户利率浮动百分点}不等于0，那么返回[执行利率]等于{产品利率}+{账户利率浮动百分点}；b.若{账户利率浮动百分比}不等于0，那么返回[执行利率]等于{产品利率}*（1+{账户利率浮动百分比}）；c.若{账户固定利率}不等于0，那么返回[执行利率]等于{账户固定利率}。输入字段为空时视同0参与条件判定，不触发对应分支

## 输入

| 字段名 | 类型 | 标记 | 来源实体 | 说明 |
|--------|------|------|----------|------|
| acctSpreadRate | java.math.BigDecimal | 非必填 | | 账户利率浮动百分点 |
| acctPercentRate | java.math.BigDecimal | 非必填 | | 账户利率浮动百分比 |
| acctFixedRate | java.math.BigDecimal | 非必填 | | 账户固定利率 |
| productRate | java.math.BigDecimal | 非必填 | | 产品利率；为空时在a、b分支的计算中视同0 |

## 输出

| 字段名 | 类型 | 标记 | 来源实体 | 说明 |
|--------|------|------|----------|------|
| realRate | java.math.BigDecimal | 非必填 | | 执行利率 |
