# BR006 设置自贸区种类

- 规则类型：决策类

## 规则描述

a.若{客户类型}等于"100-个人"且{对私客户标志}等于"Y-个人"且{税收居民标识}等于"1-中国税收居民"或者"3-既是中国税收居民又是其他国家（地区）税收居民"，则返回[自贸区种类]等于"FTI-区内个人自由贸易账户";

b.若{客户类型}等于"100-个人"且{税收居民标识}等于"2-非中国税收居民"，则返回[自贸区种类]等于"FTF-区内境外个人自由贸易账户"；

c.若{客户类型}等于"200-对公"且{境内境外标志}等于"Y-境内"，则返回[自贸区种类]等于"FTE-区内机构自由贸易账户"；
d.若{客户类型}等于"200-对公"且{境内境外标志}等于"N-境外"，则返回[自贸区种类]等于"FTN-境外机构自由贸易账户"；
e.若{客户类型}等于"300-同业"且{境内境外标志}等于"N-境外"，则返回[自贸区种类]等于"FTU-同业机构自由贸易账户"；
