# BR006 检查交易机构和基本户开户机构互斥性

## 目标与范围

**目标**：实现断言类规则 BR006「检查交易机构和基本户开户机构互斥性」。规则比较「交易机构」与「基本存款账户开户行行号」，并结合「账户属性」判定：当账户属性为"11002-一般存款账户"且交易机构与基本存款账户开户行行号为同一机构时，判定为**不通过**；其余合法取值组合判定为**通过**。判定结论以布尔返回值表达（通过 → `true`，不通过 → `false`）。

**范围内**：

- 三个输入（`tranBranch`、`acctNatureNo`、`acctBranch`）的字段契约：字段名、中文名、类型、必填性、取值来源与参数顺序。
- 枚举绑定：`tranBranch` / `acctBranch` 绑定 `com.dcits.depsit.enums.TranBranch`；`acctNatureNo` 绑定 `com.dcits.depsit.enums.AcctNatureNo`，以及"11002-一般存款账户"的枚举码值映射。
- 命中条件（机构相同 且 账户属性为一般存款账户）→ 不通过。
- 其余合法取值组合（账户属性非一般存款账户，或机构不同）→ 通过。
- 输出「执行结果」的类型与"通过/不通过"语义。

**不在范围内**：

- 输入数据的采集、来源系统取数、字段合法性校验与外部实体查询（源需求「## 输入」表的 `来源实体` 列三行均为空，本规则不承担数据访问职责）。
- 三个输入为空（未提供值）时的行为；三者均标为必填，该情形在合法输入域之外，源需求未定义。
- 错误码、异常传播、重试、幂等与兜底默认值（断言类规则以返回值表达业务结果）。
- 账户开立、状态变更、账务处理等调用本规则之后的业务流程编排。
- 规则描述之外的制度性校验（例如依据结算账户管理办法增设的其他机构互斥或账户属性组合），源需求未要求，本 Spec 不新增。

## 输入、输出及依赖契约

### 符号约定

- `TRN`：输入 `tranBranch`，规则描述中的 `{交易机构}`。
- `ACCT_BRANCH`：输入 `acctBranch`，规则描述中的 `{账户开立行行号}`（输入说明为「基本存款账户开户行行号」）。
- `NATURE`：输入 `acctNatureNo`，规则描述中的 `{账户属性}`。

名称对应：规则描述与「## 相关枚举」把 `{交易机构}`、`{账户开立行行号}` 同列为「内部机构编号」别名，`{账户属性}` 为「账户属性」别名；按语义与 `来源实体`/说明逐一对上——`{交易机构}` = `tranBranch`（说明「交易机构号」），`{账户开立行行号}` = `acctBranch`（说明「基本存款账户开户行行号」，与规则名称「基本户开户机构」同为业务别称，指同一字段），`{账户属性}` = `acctNatureNo`。对应唯一，无需业务再确认。

## Requirements

### Requirement: REQ-001 输入契约与枚举绑定

来源：`docs/requirements/BR006.md`「## 输入」表（第 17–21 行）、「## 相关枚举」（第 25–28 行）、「## 补充说明」（第 32–34 行）

系统 SHALL 以 `tranBranch`（`com.dcits.depsit.enums.TranBranch`，必填，交易机构号）、`acctNatureNo`（`com.dcits.depsit.enums.AcctNatureNo`，必填，账户属性）、`acctBranch`（`com.dcits.depsit.enums.TranBranch`，必填，基本存款账户开户行行号）三个输入执行判定，参数顺序为 `tranBranch`、`acctNatureNo`、`acctBranch`；三个输入的取值 MUST 取自上述枚举各自的码值，系统 MUST NOT 读取这三个入参之外的业务数据（不进行实体查询或外部数据访问）。

#### Scenario: REQ-001-S01 输入字段、类型与顺序符合契约

- **GIVEN** 调用方准备交易机构号、账户属性、基本存款账户开户行行号三个必填输入
- **WHEN** 调用方按契约传入 `tranBranch = TranBranch.VALUE_351155`（`"351155"`）、`acctNatureNo = AcctNatureNo.VALUE_11002`（`"11002"`）、`acctBranch = TranBranch.VALUE_351155`（`"351155"`）并触发规则
- **THEN** 规则以三个枚举类型输入执行判定，`tranBranch` 与 `acctBranch` 同为 `TranBranch`、`acctNatureNo` 为 `AcctNatureNo`；规则不使用、也不要求这三个字段之外的输入，且不发起任何实体查询或外部调用

#### Scenario: REQ-001-S02 机构类输入取自同一枚举，可直接等值比较

- **GIVEN** `tranBranch` 与 `acctBranch` 均声明为 `com.dcits.depsit.enums.TranBranch`
- **WHEN** 规则比较 `tranBranch` 与 `acctBranch` 是否同一机构
- **THEN** 比较在同一枚举类型内按码值等值进行，`TranBranch.VALUE_351155` 与同为 `"351155"` 的 `TranBranch.VALUE_351155` 判定为同一机构，`TranBranch.VALUE_351155` 与 `TranBranch.VALUE_351156` 判定为不同机构；规则不因两个输入来自不同参数位置而做字符串拼接或截断等额外转换

### Requirement: REQ-002 交易机构与基本存款账户开户行行号相同且账户属性为一般存款账户时不通过

来源：`docs/requirements/BR006.md`「## 规则描述」（第 7 行）

当 `tranBranch` 等于 `acctBranch` 且 `acctNatureNo` 等于 `"11002"`（`AcctNatureNo.VALUE_11002`，"11002-一般存款账户"）时，系统 SHALL 返回 `boolean` 值 `false`（不通过）。判定与具体的机构编号取值无关，只要求两个机构输入相等。

#### Scenario: REQ-002-S01 机构相同且账户属性为一般存款账户

- **GIVEN** `tranBranch = TranBranch.VALUE_351155`（`"351155"`）、`acctBranch = TranBranch.VALUE_351155`（`"351155"`）、`acctNatureNo = AcctNatureNo.VALUE_11002`（`"11002"`，一般存款账户）
- **WHEN** 规则执行判定
- **THEN** 规则返回 `boolean` 值 `false`（不通过）

#### Scenario: REQ-002-S02 另一组相等的机构编号同样命中

- **GIVEN** `tranBranch = TranBranch.VALUE_352001`（`"352001"`）、`acctBranch = TranBranch.VALUE_352001`（`"352001"`）、`acctNatureNo = AcctNatureNo.VALUE_11002`（`"11002"`）
- **WHEN** 规则执行判定
- **THEN** 规则返回 `boolean` 值 `false`（不通过），与 REQ-002-S01 中取 `"351155"` 时结果一致——判定只取决于两个机构输入是否相等

### Requirement: REQ-003 账户属性不是一般存款账户时通过

来源：`docs/requirements/BR006.md`「## 规则描述」（第 7 行，"否则返回执行结果为'通过'"）

当 `acctNatureNo` 不等于 `"11002"` 时，无论 `tranBranch` 与 `acctBranch` 是否相等，系统 SHALL 返回 `boolean` 值 `true`（通过）。

#### Scenario: REQ-003-S01 机构相同但账户属性为基本存款账户

- **GIVEN** `tranBranch = TranBranch.VALUE_351155`（`"351155"`）、`acctBranch = TranBranch.VALUE_351155`（`"351155"`）、`acctNatureNo = AcctNatureNo.VALUE_11001`（`"11001"`，基本存款账户）
- **WHEN** 规则执行判定
- **THEN** 规则返回 `boolean` 值 `true`（通过）

#### Scenario: REQ-003-S02 机构相同但账户属性为临时存款账户

- **GIVEN** `tranBranch = TranBranch.VALUE_351155`（`"351155"`）、`acctBranch = TranBranch.VALUE_351155`（`"351155"`）、`acctNatureNo = AcctNatureNo.VALUE_11003`（`"11003"`，临时存款账户）
- **WHEN** 规则执行判定
- **THEN** 规则返回 `boolean` 值 `true`（通过），即账户属性取 `"11002"` 之外的其他枚举码值时不触发不通过判定

### Requirement: REQ-004 交易机构与基本存款账户开户行行号不同时通过

来源：`docs/requirements/BR006.md`「## 规则描述」（第 7 行，"否则返回执行结果为'通过'"）

当 `tranBranch` 不等于 `acctBranch` 时，无论 `acctNatureNo` 取何值，系统 SHALL 返回 `boolean` 值 `true`（通过）。

#### Scenario: REQ-004-S01 账户属性为一般存款账户但机构不同

- **GIVEN** `tranBranch = TranBranch.VALUE_351155`（`"351155"`）、`acctBranch = TranBranch.VALUE_351156`（`"351156"`）、`acctNatureNo = AcctNatureNo.VALUE_11002`（`"11002"`，一般存款账户）
- **WHEN** 规则执行判定
- **THEN** 规则返回 `boolean` 值 `true`（通过）

#### Scenario: REQ-004-S02 机构不同且账户属性非一般存款账户

- **GIVEN** `tranBranch = TranBranch.VALUE_351155`（`"351155"`）、`acctBranch = TranBranch.VALUE_351156`（`"351156"`）、`acctNatureNo = AcctNatureNo.VALUE_11001`（`"11001"`，基本存款账户）
- **WHEN** 规则执行判定
- **THEN** 规则返回 `boolean` 值 `true`（通过）

### Requirement: REQ-005 布尔返回值与"通过/不通过"语义

来源：`docs/requirements/BR006.md`「## 输出」表（第 11–13 行）、「## 规则描述」（第 7 行）

系统 SHALL 以单一 `boolean` 返回值表达判定结论：执行结果为"通过"时返回 `true`，为"不通过"时返回 `false`；系统 MUST NOT 以错误码、异常、空对象或额外输出字段表达该结论。

#### Scenario: REQ-005-S01 通过场景返回 true、不通过场景返回 false

- **GIVEN** 规则被调用并得出判定结论
- **WHEN** 判定结论为"不通过"（如 `tranBranch = TranBranch.VALUE_351155`、`acctBranch = TranBranch.VALUE_351155`、`acctNatureNo = AcctNatureNo.VALUE_11002`）
- **THEN** 规则返回 `boolean` 值 `false`，不抛出异常、不返回错误码
- **WHEN** 判定结论为"通过"（如 `tranBranch = TranBranch.VALUE_351155`、`acctBranch = TranBranch.VALUE_351156`、`acctNatureNo = AcctNatureNo.VALUE_11002`）
- **THEN** 规则返回 `boolean` 值 `true`，不抛出异常、不返回错误码
