# BR005 计算到期日期

- 规则类型：计算类

## 规则描述

a.若{期限类型}是“日”：
那么[到期日期] = {系统日期} + {期限}天

b.若{期限类型}是“月”：
那么[到期日期] = {系统日期 }+ {期限}月
并且若 {系统日期}是月末或加月后日期无效（如31日加到2月）
那么将[到期日期]的“日”调整为该月的最后一天
c.若{期限类型}是“年”：
那么[到期日期] = {系统日期} + {期限}年
并且若{系统日期}是2月29日且到期年份不是闰年
那么将[到期日期]调整为2月28日。
你只考虑，期限类型是 “月”，“日”，“年”。

## 输入

| 字段名 | 类型 | 标记 | 说明 |
|--------|------|------|------|
| runDate | java.util.Date | 必填 | 核心运行日期 |
| term | java.lang.String | 必填 | 存期期限 |

| periodType | java.lang.String | 必填 | 期限类型 |

## 输出

| 字段名 | 类型 | 标记 | 说明 |
|--------|------|------|------|
| maturityDate | java.util.Date | 非必填 | 到期日期 |

## 提示

- 可能相关的属性：核心运行日期，类型为：java.util.Date
- 可能相关的属性：存期期限，类型为：java.lang.String
