# BR005 计算到期日期

- 规则类型：计算类

## 规则描述

a.若{期限类型}是“日”：
那么[到期日期] = {核心运行日期} + {存期期限}天

b.若{期限类型}是“月”：
那么[到期日期] = {核心运行日期}+ {存期期限}月

并且若 {核心运行日期}是月末或加月后日期无效（如31日加到2月）
那么将[到期日期]的“日”调整为该月的最后一天
c.若{期限类型}是“年”：
那么[到期日期] = {核心运行日期} + {存期期限}年
并且若{核心运行日期}是2月29日且到期年份不是闰年
那么将[到期日期]调整为2月28日
d.若{期限类型}是“周”“季”“半年”：
那么属于非法输入，直接报错，不计算[到期日期]
