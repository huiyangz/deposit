# BR003 检查允许转久悬标志

## 目标与范围

**目标**：实现断言类规则 BR003「检查允许转久悬标志」。规则根据「允许账户转久悬标志」与「是否允许转久悬」两个输入的取值组合，判定账户是否允许转久悬，并以布尔断言结果表达判定结论（“是”对应真、“否”对应假）。

**范围内**：

- 两个输入的字段契约：字段名、中文名、类型、必填性、取值与空值语义。
- 规则描述 a 的条件分支：允许账户转久悬标志为“是”且是否允许转久悬为“否”时返回“否”。
- 规则描述 b 的条件分支：允许账户转久悬标志为“否”且是否允许转久悬为空时返回“否”。
- 规则描述 c 的默认分支：不满足 a、b 时返回“是”。
- 断言类返回值的类型与“是/否”语义。

**不在范围内**：

- 久悬账户的实际状态转换、账户状态变更、动账与记账等后续处理。
- 是否允许转久悬字段的取值来源与获取方式（源需求未给出，本规则不承担数据访问职责）。
- 错误码、异常传播、重试与兜底默认值（断言类规则以返回值表达业务结果，源需求未定义这些行为）。
- 允许账户转久悬标志为必填字段的非法入参（如未提供）的处理；该情形在合法输入域之外，源需求未定义。
- 源需求所列取值之外的其他等价编码形式（见“验收范围与明确不覆盖的事项”）。

## Requirements

### Requirement: REQ-001 输入契约

来源：`docs/requirements/BR003.md`「## 输入」表（第 14–17 行）、「## 补充说明」（第 21 行）

系统 SHALL 以 `allowSuspendFlag`（类型 `java.lang.String`，必填，允许账户转久悬标志）与 `allowDormantFlag`（类型 `java.lang.String`，非必填，是否允许转久悬）两个输入执行判定，二者顺序为 `allowSuspendFlag` 在前、`allowDormantFlag` 在后；当 `allowDormantFlag` 为空（null 或空字符串）时，系统 MUST 仍以空值进入判定，不得因该字段为空而拒绝判定。

#### Scenario: REQ-001-S01 输入字段与类型符合契约

- **GIVEN** 调用方按契约准备允许账户转久悬标志与是否允许转久悬两个输入
- **WHEN** 调用方传入 `allowSuspendFlag = "Y-是"`、`allowDormantFlag = "N-否"` 并触发规则
- **THEN** 规则以两个 `java.lang.String` 类型输入执行判定，`allowSuspendFlag` 为必填、`allowDormantFlag` 为可空；规则不使用、也不要求这两个字段之外的输入

#### Scenario: REQ-001-S02 非必填字段为空时仍进入判定

- **GIVEN** 是否允许转久悬为可空输入
- **WHEN** 调用方传入 `allowSuspendFlag = "N-否"`，`allowDormantFlag` 为空（未提供值或为空字符串）
- **THEN** 规则不抛出异常、不返回错误码，`allowDormantFlag` 以空值参与判定，判定结果由 REQ-004 决定

### Requirement: REQ-002 断言类布尔返回值与“是/否”语义

来源：`docs/requirements/BR003.md`「## 规则描述」a、b、c（第 7、8、10 行）；「## 已接受的需求处理结论」（第 25–29 行）

系统 SHALL 以布尔返回值表达判定结论：“是”对应 `true`，“否”对应 `false`；系统 MUST NOT 以错误码、异常或空对象表达该判定结果。

#### Scenario: REQ-002-S01 返回布尔值且“是/否”语义正确

- **GIVEN** 规则被调用并得出判定结论
- **WHEN** 判定结论为“否”（如 `allowSuspendFlag = "Y-是"`、`allowDormantFlag = "N-否"`）
- **THEN** 规则返回 `boolean` 值 `false`
- **WHEN** 判定结论为“是”（如 `allowSuspendFlag = "Y-是"`、`allowDormantFlag = "Y-是"`）
- **THEN** 规则返回 `boolean` 值 `true`

### Requirement: REQ-003 条件 a：允许账户转久悬标志为“是”且是否允许转久悬为“否”时返回否

来源：`docs/requirements/BR003.md`「## 规则描述」a（第 7 行）

当 `allowSuspendFlag` 等于 "Y-是" 且 `allowDormantFlag` 等于 "N-否" 时，系统 SHALL 返回 `false`（“否”）。

#### Scenario: REQ-003-S01 命中条件 a

- **GIVEN** `allowSuspendFlag = "Y-是"`，`allowDormantFlag = "N-否"`
- **WHEN** 规则执行判定
- **THEN** 规则返回 `boolean` 值 `false`

### Requirement: REQ-004 条件 b：允许账户转久悬标志为“否”且是否允许转久悬为空时返回否

来源：`docs/requirements/BR003.md`「## 规则描述」b（第 8 行）

当 `allowSuspendFlag` 等于 "N-否" 且 `allowDormantFlag` 为空（null 或空字符串）时，系统 SHALL 返回 `false`（“否”）。

#### Scenario: REQ-004-S01 命中条件 b（空值为未提供值）

- **GIVEN** `allowSuspendFlag = "N-否"`，`allowDormantFlag` 未提供（null）
- **WHEN** 规则执行判定
- **THEN** 规则返回 `boolean` 值 `false`

#### Scenario: REQ-004-S02 命中条件 b（空值为空字符串）

- **GIVEN** `allowSuspendFlag = "N-否"`，`allowDormantFlag = ""`
- **WHEN** 规则执行判定
- **THEN** 规则返回 `boolean` 值 `false`

### Requirement: REQ-005 条件 c：未命中 a、b 的取值组合返回是

来源：`docs/requirements/BR003.md`「## 规则描述」c（第 10 行）

当输入取值不同时满足条件 a 与条件 b 时，系统 SHALL 返回 `true`（“是”）；该默认分支使合法输入域内的任意取值组合都有唯一确定的布尔结果。

#### Scenario: REQ-005-S01 标志为“是”且是否允许转久悬为“是”

- **GIVEN** `allowSuspendFlag = "Y-是"`，`allowDormantFlag = "Y-是"`
- **WHEN** 规则执行判定
- **THEN** 规则返回 `boolean` 值 `true`

#### Scenario: REQ-005-S02 标志为“是”且是否允许转久悬为空

- **GIVEN** `allowSuspendFlag = "Y-是"`，`allowDormantFlag` 为空（null 或空字符串）
- **WHEN** 规则执行判定
- **THEN** 规则返回 `boolean` 值 `true`

#### Scenario: REQ-005-S03 标志为“否”且是否允许转久悬为“是”

- **GIVEN** `allowSuspendFlag = "N-否"`，`allowDormantFlag = "Y-是"`
- **WHEN** 规则执行判定
- **THEN** 规则返回 `boolean` 值 `true`

#### Scenario: REQ-005-S04 标志为“否”且是否允许转久悬为“否”

- **GIVEN** `allowSuspendFlag = "N-否"`，`allowDormantFlag = "N-否"`
- **WHEN** 规则执行判定
- **THEN** 规则返回 `boolean` 值 `true`

#### Scenario: REQ-005-S05 取值不属于条件 a、b 所列取值

- **GIVEN** 输入取值不等于条件 a、b 所列的任何一种取值组合（例如 `allowSuspendFlag = "X"`、`allowDormantFlag = "Y"`，二者均非 "Y-是"、"N-否"，亦非空）
- **WHEN** 规则执行判定
- **THEN** 规则落入条件 c 的默认分支，返回 `boolean` 值 `true`
