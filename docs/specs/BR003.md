# BR003 检查允许转久悬标志

- 规则类型：断言类

## 规则描述

a.若 {允许账户转久悬标志} 等于"Y"且{是否允许转久悬}等于"N"，则返回否；
b.若 {允许账户转久悬标志} 等于"N"且{是否允许转久悬}为空（null 或空字符串），则返回否；

c.否则，返回是

## 输入

| 字段名 | 类型 | 标记 | 来源实体 | 说明 |
|--------|------|------|----------|------|
| allowSuspendFlag | java.lang.String | 必填 | | 允许账户转久悬标志 |
| AllowDormantFlag | java.lang.String | 非必填 | | 是否允许转久悬 |

## 输出

| 字段名 | 类型 | 标记 | 来源实体 | 说明 |
|--------|------|------|----------|------|
| result | boolean | 必填 | | 检查结果（是/否） |

## 提示

- 可能相关的属性：允许账户转久悬标志，类型为：java.lang.String
