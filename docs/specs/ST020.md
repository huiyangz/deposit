# ST020 检查交易金额

## 步骤描述

1.检查交易金额：若{交易金额}小于等于0，则返回[错误码]“ER0050”，否则返回检查结果为“通过”

## 输入

| 字段名 | 类型 | 标记 | 来源实体 | 说明 |
|--------|------|------|----------|------|
| tranAmt | java.math.BigDecimal | 必填 | | 交易金额 |

## 输出

本步骤无额外业务输出字段，检查结论由 StepResult 继承状态字段表达：检查结果为“通过”对应 succeed=true（errorCode、errorMessage 为空）；交易金额小于等于 0 时对应 succeed=false、errorCode=“ER0050”。
