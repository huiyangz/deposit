# ST037 检查通兑标志

## 步骤描述

1.获取产品的通兑标志：根据 {产品编号}，{参数KEY值}访问业务组件《产品管理》的 业务功能《查询产品信息》 ，获取 $通兑标志$

2.检查通兑标志是否在产品配置的范围内：a.账户{通兑标志}不等于空时，若产品[通兑标志]为“N-不允许通兑”且账户{通兑标志}不为“N-不允许通兑”，则返回[错误码]“ER0018”，否则继续执行。

b.账户{通兑标志}等于空时，则继续执行。
3.检查通兑机构号：若{通兑标志}等于"D-指定机构通兑"且{通兑机构编号}等于"空"，则返回[错误码]“ER0019”，否则继续执行。

4.获取机构币种：根据{通兑机构编号}查询【机构币种信息】（机构币种表 FM_BRANCH_CCY，按归属机构号查询）获取[机构币种列表]。

5.检查账户币种和机构币种匹配性：仅当{通兑标志}为“分行间通兑”或“指定机构间通兑”时，检查{币种}是否在[机构币种列表]范围内，不在则返回[错误码]“ER0020”；其余情况返回检查结果为“通过”。
