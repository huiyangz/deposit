# ST024 更新现金存入后现金尾箱

## 步骤描述

1.获取柜员现金尾箱编号：根据{柜员号}、{尾箱属性}为“现金尾箱”或“组合尾箱”查询【尾箱基本信息表】获取$尾箱编号$

2.获取尾箱现金余额：根据[尾箱编号]查询【尾箱现金余额】获取$金额$（本步骤按单币种处理，尾箱编号在尾箱现金余额表中对应唯一记录）

3.计算尾箱现金余额：[尾箱余额]=[金额]+{交易金额}
4.更新尾箱现金余额：根据[尾箱编号]更新【尾箱现金余额】的$金额$为[尾箱余额]
