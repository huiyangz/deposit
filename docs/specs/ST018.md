# ST018 检查分行法人透支额度

## 目标与范围

本任务将正式需求「检查分行法人透支额度」交易执行步骤整理为可验证的 Spec。步骤按序执行三个子动作：

1. 获取分行机构号：根据交易机构号查询【机构信息】获取该机构对应的[分行机构]；
2. 获取分行法人透支额度：根据分行机构号查询【机构法人透支额度信息表】获取已使用额度和总额度；
3. 检查分行已使用额度：已使用额度小于等于总额度时跳转至步骤《检查法透账户支取限制》，否则返回错误码“ER0062”。

范围限于 ST018 需求文档「步骤描述」第 1–3 条、「输入」「输出」表及「相关枚举」「补充说明」声明的契约。跳转目标《检查法透账户支取限制》属后续流程步骤，需求未提供其任务编号与行为，本 Spec 按原文名称引用、不展开其行为。查询无记录、额度字段为空、必填输入缺失等需求未定义情形记录于「待确认事项」，不补默认行为。

## 输入、输出及依赖契约

### 输入

| 字段名 | 类型 | 必填性 | 来源实体 | 说明 |
|---|---|---|---|---|
| `tranBranch` | `com.dcits.deposit.enums.TranBranch` | 必填 | 未在需求中指定（由调用方提供） | 交易机构号 |

### 输出

| 字段名 | 类型 | 必填性 | 来源实体 | 说明 |
|---|---|---|---|---|
| `branch` | `com.dcits.deposit.enums.TranBranch` | 非必填 | 机构信息表（FM_BRANCH） | 归属机构号（分行机构号） |
| `totalLimit` | `java.math.BigDecimal` | 非必填 | 机构法人透支额度信息表（RB_OD_BRANCH_INFO） | 总额度 |
| `usedAmt` | `java.math.BigDecimal` | 非必填 | 机构法人透支额度信息表（RB_OD_BRANCH_INFO） | 已使用额度 |

### 确认的步骤流程

1. 获取分行机构号：以交易机构号 `tranBranch` 查询【机构信息】（FM_BRANCH），输出匹配记录的「归属机构号」作为分行机构号 `branch`；
2. 获取分行法人透支额度：以 `branch`（分行机构号）查询【机构法人透支额度信息表】（RB_OD_BRANCH_INFO），输出「已使用额度」`usedAmt` 与「总额度」`totalLimit`；
3. 检查分行已使用额度：若 `usedAmt` 小于等于 `totalLimit`，跳转至步骤《检查法透账户支取限制》；否则步骤业务失败，返回错误码 “ER0062”。

### 依赖核对

- 枚举 `com.dcits.deposit.enums.TranBranch`（内部机构编号）存在于 `deposit-common`，值为机构码（如 `VALUE_351156("351156")`），提供 `getValue()` 取码值、`byValue(String)` 按码值解析。需求「补充说明」确认：交易机构号、归属机构号取值来源于代码[内部机构编号]，对应枚举类 `com.dcits.deposit.enums.TranBranch`。
- 【机构信息】＝机构信息表 FM_BRANCH：实体 `FmBranch` / EO `FmBranchEO` 含字段 `branch`（归属机构号，EO 类型 `TranBranch`）；数据服务接口 `IFmBranchBcc.findByBranch(TranBranch)` 按「归属机构号」查询，无匹配记录返回 `null`。
- 【机构法人透支额度信息表】＝RB_OD_BRANCH_INFO：实体 `RbOdBranchInfo` / EO `RbOdBranchInfoEO` 含字段 `usedAmt`（已使用额度，`BigDecimal`）、`totalLimit`（总额度，`BigDecimal`）、`branch`（归属机构号，EO 类型 `TranBranch`）；数据服务接口 `IRbOdBranchInfoBcc.findByBranch(TranBranch)` 按「归属机构号」查询，无匹配记录返回 `null`。
- 步骤结果公共契约：`com.dcits.common.step.StepResult` 含 `succeed`、`errorCode`（成功时为 null）、`errorMessage`（成功时为 null）；`com.dcits.common.step.GotoStepCondition` 注解通过 `candidateSteps` 声明可跳转步骤，运行时按步骤返回结果的跳转目标决定流转。当前公共类未完整暴露跳转目标字段，本 Spec 按需求约定表述成功流转与失败短路，不假定具体字段名。
- 错误码：`deposit-application/src/main/resources/errorcodes.properties` 定义 `ER0062=分行法人透支额度超限`，与需求返回的错误码一致。
- 名称映射资产（requirement-name-mapping）：「机构信息」→ 实体「机构信息表」已收录且一致；「机构法人透支额度信息表」「分行机构」「交易机构」及属性域「交易机构号」「归属机构号」「已使用额度」「总额度」「内部机构编号」未收录映射，本 Spec 按需求原文业务称谓表述。

## Requirements

### Requirement: REQ-001 交易机构号输入契约

来源：需求「输入」表（tranBranch）及「相关枚举」「补充说明」（原文：{交易机构号,输入数据-交易机构号,归属机构号,输出数据-归属机构号}取值来源于代码[内部机构编号]，对应枚举类-类名：com.dcits.deposit.enums.TranBranch）

系统 SHALL 接受必填输入 tranBranch，其类型为 `com.dcits.deposit.enums.TranBranch`（内部机构编号），取值来源于代码[内部机构编号]；步骤以该值作为查询【机构信息表】的交易机构号。

#### Scenario: REQ-001-S01 有效交易机构号驱动机构信息查询

- **GIVEN** 调用方提供交易机构号 tranBranch = `TranBranch.VALUE_351156`（示例数据，码值 351156）
- **WHEN** 执行步骤「检查分行法人透支额度」
- **THEN** 步骤以 tranBranch 的值查询机构信息表（FM_BRANCH），且该输入取值属于枚举 `com.dcits.deposit.enums.TranBranch`

### Requirement: REQ-002 根据交易机构号获取分行机构号

来源：需求「步骤描述」第 1 条（原文：获取分行机构号：根据{交易机构}查询【机构信息】获取该机构对应的[分行机构]）及「输出」表 branch 行（原文：归属机构号，来源实体：机构信息表（FM_BRANCH））

系统 SHALL 以交易机构号 tranBranch 查询机构信息表（FM_BRANCH），并输出匹配记录中的「归属机构号」作为分行机构号 branch，其类型为 `com.dcits.deposit.enums.TranBranch`。

#### Scenario: REQ-002-S01 机构信息表中存在交易机构记录时输出分行机构号

- **GIVEN** 机构信息表（FM_BRANCH）中存在交易机构号对应的机构记录，且该机构对应的分行机构号为 `TranBranch.VALUE_352001`（示例数据，大同分行）
- **WHEN** 执行「获取分行机构号」
- **THEN** 步骤输出 branch = `TranBranch.VALUE_352001`，作为后续查询分行法人透支额度的查询键

### Requirement: REQ-003 根据分行机构号获取分行法人透支额度

来源：需求「步骤描述」第 2 条（原文：获取分行法人透支额度：根据[分行机构]查询【机构法人透支额度信息表】获取当前分行的机构法人透支额度的$已使用额度$和$总额度$）及「输出」表 totalLimit、usedAmt 行

系统 SHALL 以分行机构号 branch 查询机构法人透支额度信息表（RB_OD_BRANCH_INFO），并输出匹配记录的「已使用额度」usedAmt 与「总额度」totalLimit，二者类型均为 `java.math.BigDecimal`。

#### Scenario: REQ-003-S01 分行机构透支额度记录存在时输出已使用额度与总额度

- **GIVEN** 机构法人透支额度信息表（RB_OD_BRANCH_INFO）中存在归属机构号为 branch（分行机构号）的记录，其总额度 totalLimit = 100.00、已使用额度 usedAmt = 80.00（示例数据）
- **WHEN** 执行「获取分行法人透支额度」
- **THEN** 步骤输出 totalLimit = 100.00 且 usedAmt = 80.00，均按 `java.math.BigDecimal` 表示

### Requirement: REQ-004 检查分行已使用额度并决定流转

来源：需求「步骤描述」第 3 条（原文：检查分行已使用额度：若{已使用额度}小于等于{总额度}，则跳转至步骤《检查法透账户支取限制》，否则返回[错误码]“ER0062”）

当已使用额度 usedAmt 小于等于总额度 totalLimit 时，系统 SHALL 以成功状态完成本步骤并跳转至步骤《检查法透账户支取限制》（成功状态下 errorCode、errorMessage 为空）；当 usedAmt 大于 totalLimit 时，系统 SHALL 将本步骤判定为业务失败并返回错误码 “ER0062”（分行法人透支额度超限），不跳转至《检查法透账户支取限制》。

#### Scenario: REQ-004-S01 已使用额度等于总额度时跳转（边界相等）

- **GIVEN** 已使用额度 usedAmt = 100.00、总额度 totalLimit = 100.00（两值相等）
- **WHEN** 执行「检查分行已使用额度」
- **THEN** 步骤成功（errorCode、errorMessage 为空），并跳转至步骤《检查法透账户支取限制》

#### Scenario: REQ-004-S02 已使用额度小于总额度时跳转

- **GIVEN** 已使用额度 usedAmt = 80.00、总额度 totalLimit = 100.00（已使用额度小于总额度）
- **WHEN** 执行「检查分行已使用额度」
- **THEN** 步骤成功（errorCode、errorMessage 为空），并跳转至步骤《检查法透账户支取限制》

#### Scenario: REQ-004-S03 已使用额度大于总额度时返回错误码

- **GIVEN** 已使用额度 usedAmt = 120.00、总额度 totalLimit = 100.00（已使用额度大于总额度）
- **WHEN** 执行「检查分行已使用额度」
- **THEN** 步骤判定为业务失败，errorCode = “ER0062”，errorMessage = “ER0062::分行法人透支额度超限”，且不跳转至步骤《检查法透账户支取限制》

## 待确认事项

- **TBD-1（关联 REQ-002、REQ-003）[分行机构]与机构信息表字段的对应关系**：需求步骤 1 表述为「根据{交易机构}查询【机构信息】获取该机构对应的[分行机构]」，输出表将输出字段声明为「归属机构号」（类型 `TranBranch`，来源机构信息表 FM_BRANCH）。现有组件 `IFmBranchBcc.findByBranch(TranBranch)` 按 FM_BRANCH 的「归属机构号」列查询并返回记录（该列同时为表主键，记录的归属机构号与查询键同值）。需求未说明交易机构号与分行机构号的关系：分行机构号是否即交易机构号对应的机构记录之「归属机构号」，还是需经记录中「归属上级机构号」（attachedTo）等其它字段换算（输出表未登记该字段）。需确认分行机构号的取数字段与查询键；确认前本 Spec 按输出表声明整理（分行机构号＝机构信息表记录的「归属机构号」），场景 REQ-002-S01 的样例值仅作示例数据，未绑定取数实现。
- **TBD-2（关联 REQ-002）机构信息查询无记录**：按交易机构号查询机构信息表（FM_BRANCH）无匹配记录时，需求未定义行为（是否业务失败、返回错误码，或跳过后续检查）。需确认。
- **TBD-3（关联 REQ-003）分行法人透支额度查询无记录**：按分行机构号查询机构法人透支额度信息表（RB_OD_BRANCH_INFO）无匹配记录时，需求未定义行为。需确认。
- **TBD-4（关联 REQ-003、REQ-004）额度字段为空**：记录存在但「已使用额度」或「总额度」为 null 时，「已使用额度小于等于总额度」的比较结果未定义。需确认处理方式。
- **TBD-5（关联 REQ-001）必填输入缺失**：tranBranch 标记为必填，但需求未定义其为空（null）或无效取值时的行为。需确认是否返回错误及错误码。
