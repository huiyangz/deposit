# DT001 根据核准类型设置账户状态

- 规则类型：决策类

## 规则描述

1.若{账户属性}为“基本户”，则：
a.若{境内境外标志}为“境内”且{企业标志}为“是”，则返回[账户状态]为“新建”
b.若{境内境外标志}为“境内”且{企业标志}为“否”，则返回[账户状态]为“预开户”
c.若{境内境外标志}为“境外”且{企业标志}为“是”，则返回[账户状态]为“预开户”
d.若{境内境外标志}为“境外”且{企业标志}为“否”，则返回[账户状态]为“新建”
2.若{账户属性}为"一般户"，则返回[账户状态]为"新建"
3.若{账户属性}为"专用户"（仅对应账户属性枚举中的"专用存款账户"），则：

3.1.若{对公存款账户用途}为"预算单位专用存款户"：

a.若{境内境外标志}为“境内”且{企业标志}为“是”，则返回[账户状态]为空值（null）。

b.若{境内境外标志}为"境内"且{企业标志}为"否"，则返回[账户状态]为"预开户"
c.若{境内境外标志}为"境外"且{企业标志}为"是"，则返回[账户状态]为空值（null）。

d.若{境内境外标志}为"境外"且{企业标志}为"否"，则返回[账户状态]为"新建"
3.2.若{对公存款账户用途}为"非预算单位专用存款户"，则返回[账户状态]为"新建"
3.3.否则，返回[账户状态]为"新建"

4.若{账户属性}为"临时户"，则：
a.若{境内境外标志}为"境内"且{企业标志}为"是"，则返回[账户状态]为"新建"
b.若{境内境外标志}为"境内"且{企业标志}为"否"，则返回[账户状态]为"预开户"
c.若{境内境外标志}为"境外"且{企业标志}为"是"，则返回[账户状态]为空值（null）。
d.若{境内境外标志}为"境外"且{企业标志}为"否"，则返回[账户状态]为"新建"
5.若{账户属性}为"验资户"，则：
a.若{境内境外标志}为"境内"且{企业标志}为"是"，则返回[账户状态]为"新建"
b.若{境内境外标志}为"境内"且{企业标志}为"否"，则返回[账户状态]为"新建"
c.若{境内境外标志}为"境外"且{企业标志}为"是"，则返回[账户状态]为空值（null）。
d.若{境内境外标志}为"境外"且{企业标志}为"否"，则返回[账户状态]为"新建"
6.否则，返回[账户状态]为“新建”
