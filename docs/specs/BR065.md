# BR065 检查客户类型是否在产品配置范围内

- 规则类型：断言类

## 规则描述

如果产品的{客户类型}包括客户的{客户类型}，则返回是，否则返回否

## 输入

| 字段名 | 类型 | 标记 | 说明 |
|--------|------|------|------|
| clientType | com.dcits.deposit.enums.ClientType | 必输| 客户类型 |
| prodClientType | java.lang.String |必输 | 产品的客户类型 |

## 输出

| 字段名 | 类型 | 标记 | 说明 |
|--------|------|------|------|
| executionResult | java.lang.String | | 执行结果 |
