# ST030 检查账号

## 步骤描述

1.检查定制账户标志：若{定制账户标志}为“N-非定制账户”，则跳转至子步骤《检查是否上送账号》，否则跳转至子步骤《根据定制账号获取账户信息》
2.检查是否上送账号：若已上送{账号}，则跳转至子步骤《获取预留账户信息》，否则返回检查结果为“通过”。
3.获取预留账户信息：根据{账号}且$预约状态$为“S-预约成功”查询【账号预约信息】获取[预留账户信息]

4.检查预留账号：若[预留账户信息]不为空，则返回检查结果为“通过”，否则返回[错误码]“ER0025”。
5.根据定制账号获取账户信息：若{账号}不等于空，且{定制账户标志}等于“A-全账户定制”，则根据{账号}查询【账户信息】获取[账户信息]；否则返回检查结果为“通过”。

6.检查定制账号存在性：若[账户信息]存在，则返回[错误码]“ER0026”，否则返回检查结果为“通过”。
