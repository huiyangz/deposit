# ST055 设置账号

## 步骤描述

1.检查定制账户标志：若{定制账户标志}等于“A-全账户定制”，则跳转至子步骤《赋值定制账号》，否则跳转至子步骤《设置账号生成规则类型》
2.赋值定制账号：赋值[账号]为{账号}，跳转至子步骤《根据非居民标志设置账号前缀》
3.设置账号生成规则类型：赋值 [账号生成规则类型] 等于“AC”
4.生成账号：根据 [账号生成规则类型]、 {交易机构}、{产品编号}，访问业务组件《基础公共》的业务功能《生成账号》，获取$账号$并赋值[账号]为$账号$，跳转至子步骤《根据非居民标志设置账号前缀》

5.根据非居民标志设置账号前缀：
1.设置账号前缀
a.若{非居民账户标志}等于“Y-是”且{境内境外标志}等于"N-境外"，则赋值并返回[账号]为“NRA”+[账号]；
b.若{非居民账户标志}等于“N-否”，则赋值输出参数[账号]为[账号]

2.跳转至子步骤《获取自贸区机构标志》
6.获取自贸区机构标志：根据{开户机构}查询【机构信息】获取$自贸区机构标志$
7.设置非自贸区机构账户的账号：若[自贸区机构标志]为“Y-是”，则继续执行，否则返回输出参数[账号]。
8.获取客户信息：根据{客户号}查询【客户信息】获取$境内境外标志$$税收居民标志$$客户类型$$对私客户标志$
9.获取自贸区种类：根据{境内境外标志}{税收居民标志}{客户类型}{对私客户标志}执行规则《设置自贸区种类》,获取[自贸区种类]

10.设置自贸区机构账户的账号：若[自贸区机构标志]等于“Y-是”，则根据自贸区种类拼接系统自动生成的账号：

a.若[自贸区种类]等于"FTI-区内个人自由贸易账户"，则赋值并返回[账号]为“FTI”+[账号]；
b.若[自贸区种类]等于"FTF-区内境外个人自由贸易账户"，则赋值并返回[账号]为“FTF”+[账号]；
c.若[自贸区种类]等于"FTE-区内机构自由贸易账户"，则赋值并返回[账号]为“FTE”+[账号]；
d.若[自贸区种类]等于"FTN-境外机构自由贸易账户"，则赋值并返回[账号]为“FTN”+[账号]；
e.若[自贸区种类]等于"FTU-同业机构自由贸易账户"，则赋值并返回[账号]为“FTU”+[账号]
