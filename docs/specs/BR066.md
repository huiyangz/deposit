# BR066 检查境内境外标志是否在产品配置范围内

- 规则类型：断言类

## 规则描述

如果产品的{境内境外标志}为“Y”，且客户的{境内境外标志}为“Y”，则返回是；
如果产品的{境内境外标志}为“N”，且客户的{境内境外标志}为“N”，则返回是；
否则返回否

## 输入

| 字段名 | 类型 | 标记 | 说明 |
|--------|------|------|------|
| customerDomesticOverseasFlag | java.lang.String | 必输| 客户的境内境外标志 |
| productDomesticOverseasFlag | java.lang.String | 必输| 产品的境内境外标志 |

## 输出

| 字段名 | 类型 | 标记 | 说明 |
|--------|------|------|------|
| executionResult | java.lang.String | | 执行结果 |
